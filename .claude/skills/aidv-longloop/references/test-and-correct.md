# 測試與矯正＋真實腳本實測（步驟 8–9、12–13）

> 三層防線：**步驟 8 完成度測試**（依卡型）→ **步驟 9/13 矯正協定**（找根因、反覆修正）→ **步驟 12 真實腳本實測**（真站、真實素材、模擬使用者）。
> 原則：「寫完 ≠ 測過」「PR 綠 ≠ 真站會動」「mock 過 ≠ 真實腳本過」。

---

## 步驟 8 — 完成度測試矩陣（取卡型對應列，全綠才過測試門）

| 卡型 | 必跑 | 通過條件 |
|---|---|---|
| 共通（每張） | `npx tsc --noEmit`／`npm run check:routes`／`npm run check:navigation` | 型別綠、路由/registry 對齊、無 `window.location` 內部導航 |
| 視覺/UIUX | `npx vitest run <元件><鄰測>`＋四態/a11y/RWD/persona | 四態有出口、對比≥4.5:1、桌機/手機皆走得通 |
| 後端/接線 | `vitest`（procedure 行為）＋`check:routes` | 契約輸入/輸出/錯誤碼符合；既有測不退 |
| 基建/耐久/migration | 耐久性測＋`migration-prod-pending-block`＋`orphan-migrations-journal`＋回滾演練 | 殺行程任務存活、SSE 重連、migration 可前可後可回滾 |
| 安全/維運 | magic-byte/移除 SVG＋fail-closed＋限流＋金鑰不外洩 | 惡意輸入被擋、預設拒絕、金鑰只在 Railway |
| 資料/RAG | recall-vs-ef_search sweep＋注入側門 | recall 達標、教材庫內容不被當指令執行 |
| AI 代理/planner | `npm run eval`＋沙箱逃逸/權限越界 | 規劃器無回歸、沙箱擋住越權與 egress |

> 避雷：main baseline 13 failed/6 檔（jsdom29+vitest2 localStorage）＝既有，判新回歸時**扣掉這 13**（AIDV-29）。

## 步驟 9／13 — 矯正協定（反覆修正的紀律，避免亂修/越修越歪）
1. **先找根因**：讀 failing test 訊息、server log、（PR）審查事件、瀏覽器 console/network。**不貼症狀補丁**。
2. **一次一假設**：只改一個地方→只重跑「該測＋鄰測（回歸）」，確認沒按下葫蘆浮起瓢。
3. **連兩輪同因未解＝STOP**：`AskUserQuestion` 問 Bruce（縮範圍/拆卡/換做法），**不硬撞、不亂改大範圍**（漂移訊號）。
4. **矯正過對齊門**：修 bug 不可順勢擴張範圍/接新後端/碰金鑰。
5. 修好補一條**回歸測試**鎖住，避免再犯。

## 步驟 12 — 真實腳本實測（淡大腳本／真站模擬使用者）

> 定義（Bruce 2026-06-18）：**用開發好的網站實測，放入真實腳本素材與各種情境，模擬使用者實際用網站**。不是 mock、不是只跑 CI 自動化——是真站、真內容、真旅程。

### 前置
- 步驟 11 已合併、Railway 部署完成、`/api/health` 綠、無 pending migration block。
- 準備**真實腳本素材**：真的一段 logline／世界觀／角色設定／劇本（非佔位字）。
- 工具：**Claude in Chrome**（`mcp__Claude_in_Chrome__*`）實際開真站點擊、輸入、觀察；必要時 Playwright 腳本輔助重跑。

### 跑法（模擬真實使用者旅程）
1. 開真站，依**多情境**各跑一輪（至少 2–3 個）：
   - 新手手機創作者：引導表單→第一支草稿。
   - 回訪桌機創作者：既有專案→/video 六步改一個鏡→匯出。
   - 社群短影音作者：/social 九步 S1–S9。
   - （依本卡功能挑會觸發它的情境）
2. **放真實素材**走完整旅程（影片＝logline→世界觀/風格→劇本→分鏡→生成→初剪→匯出）。
3. 觀察**三柱真的活著**：
   - **生成**：provider 門面實打到模型、有真實產出；成本 `cost_aggregations` 有落帳非 $0.00。
   - **儲存**：媒體存得進 R2/儲存、連結取得回；血統（prompt↔asset）有寫入。
   - **工作流**：六步接得上、單次重啟不全失、該卡功能在真旅程中被正確觸發。
4. 記每個**卡點**（哪步、什麼輸入、預期 vs 實際、console/network 證據）。

### 反覆修正到通
- 每個卡點 → 步驟 13 套**矯正協定** → 重新部署 → **重跑該情境** → 直到「**真實腳本能從頭跑到匯出**」。
- 通過＝多情境真實素材在真站全綠；**不得用 mock 假裝通過**（漂移訊號）。
- 同一卡點連兩輪未解 → 問 Bruce（可能要拆卡或補金鑰）。

### 實測報告（貼回 Jira 卡，署名 — 智能助手 🤖）
- 情境 × 三柱結果表（綠/紅＋證據連結）。
- 已修卡點清單（根因→修法→回歸測）。
- 殘留已知限制（如耐久佇列 AIDV-13 未上前的 5 分鐘 timeout）＋對應追蹤卡。
