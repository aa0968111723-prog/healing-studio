# 反跑偏護欄（🧭 對齊門 · 不准跑偏）

> 目的：長循環跑很多步、很多卡，最容易「越做越歪」——範圍偷偷長大、順手接了新後端、同時開好幾張卡、最後哪張都沒收。本檔把「不跑偏」變成每階都過的可勾清單。
> 根據：benchmark 報告主題 8——單人開發最大隱形成本＝context-switching 與「很多東西快做完但都沒完成」；WIP 限制（個位數/1）是解法。

## 🧭 對齊門（每進下一階前，五問全 yes 才前進）
1. **同一張卡？** 還在認領的那張，沒偷換、**沒同時動多卡（WIP=1）**。
2. **範圍沒長大？** 與工作表「範圍一句話」一致，沒夾「順便」、沒從一句變三句。
3. **檔案在清單內？** 只動工作表「檔案」欄列的檔，沒擴散到 out-of-scope。
4. **仍對北極星？** 這步真的在推進 logline→成片六步，不是離題的精緻化。
5. **沒踩 Bruce 門？** 沒順手接新後端/碰金鑰/改 prod 行為（碰到＝停下等拍板）。

> 一句話自檢：『如果 Bruce 現在問我「你在做哪張卡的哪一步」，我答得出**單一**答案嗎？』答不出＝已經跑偏。

## 漂移訊號（任一出現＝立刻 STOP-realign）
- 開始改**不在檔案清單**的檔案。
- 心裡冒出「**順便也把 X 做一做**」。
- 為了讓測試過，去**改測試**而不是改程式（除非測試本身錯）。
- 範圍描述從**一句**變成**多句**、開始用「以及/還有/順便」。
- **同時**有兩張以上卡在「進行中」。
- 用 **mock/假資料**假裝通過了「真實情境」。
- 連續修同一個 bug **超過兩輪**還在原地打轉。

## STOP-realign 協定（偵測到漂移時）
1. **停**——先別再寫。
2. **寫下偏離點**：我原本要做 A，現在在做 B，B 是怎麼冒出來的。
3. **回工作表**重讀「範圍一句話」與「檔案清單」。
4. **新發現開新卡**：B 若有價值→在 Jira 開新卡（label 對應 Wave），**連結但不併進當前卡**；不擴張當前範圍。
5. **回到唯一下一步**：當前卡的下一個動作，或停下等 Bruce 拍板。

## WIP=1 紀律
- 同一時間只有**一張卡**在「進行中」、只有**一個**下一步。
- 想平行開多卡/多 AI 任務＝context-switching 成本放大器，**禁**。要換卡先把當前卡收到一個乾淨的停損點（PR draft/留言記錄）。
- 卡住等 Bruce（拍板/金鑰/合併）時，**不要為了「有事做」去偷跑下一張卡**——記下、等、回報。

## 與測試矯正的關係
- 矯正（步驟 9/13）**也要過對齊門**：修 bug 不可順勢擴張範圍或接新後端。
- 「反覆修正」是**在同一張卡的範圍內**打轉到綠，不是越修範圍越大。
