# 全站光球代理：Perplexity 深度搜尋指南

## 簡介

全站光球代理現已整合 **Perplexity Sonar API**，具備強大的外部網路深度搜尋能力。當您需要查詢最新的技術趨勢、產品比較、時事新聞或特定領域知識時，光球可以主動連網搜尋，並提供附帶引用來源的結構化摘要。

## 如何觸發深度搜尋？

光球具備智慧意圖辨識能力。只要在對話框中使用以下關鍵字或句型，光球就會自動啟動外部搜尋：

- **明確指令**：「搜尋」、「查詢」、「查找」、「幫我查」、「上網搜」
- **趨勢與新聞**：「最新」、「最近」、「趨勢」、「動態」、「新聞」
- **比較與推薦**：「比較」、「差異」、「哪個好」、「推薦」、「評價」
- **知識與原理**：「是什麼」、「如何做」、「為什麼」、「原因」、「解釋」

### 💡 範例對話

* ❌ **錯誤示範（會觸發站內生成）**：「幫我生成一張最新的 AI 圖片」
* ✅ **正確示範（會觸發深度搜尋）**：「幫我搜尋 2026 年最新的 AI 圖片生成技術趨勢」
* ✅ **正確示範（會觸發深度搜尋）**：「請查一下 Sora 和 Kling 影片生成模型的優缺點比較」

## 搜尋結果呈現

當光球完成搜尋後，會為您提供：

1. **綜合摘要**：彙整多個來源的重點資訊（約 300-500 字）。
2. **引用來源**：附上可點擊的原文連結，讓您可以深入閱讀。
3. **自動記錄**：重要的搜尋結果可選擇自動存入您的「學習文件中心」，方便日後查閱。

## 多層備援機制 (Fallback Strategy)

為了確保搜尋服務的穩定性，光球採用了三層備援機制：

1. **Perplexity Native API**：首選提供者，提供最高品質的摘要與引用來源。
2. **OpenRouter Sonar**：當原生 API 暫時不可用時，透過 OpenRouter 轉接。
3. **Brave Search**：最後的備援方案，提供純粹的搜尋引擎結果。

## 與多步驟代理的結合

深度搜尋不僅能單獨使用，還能作為創作流程的第一步：

1. **先查資料**：「幫我搜尋 2026 春夏最流行的網頁設計風格」
2. **後續創作**：（看完結果後）「請根據剛剛搜尋到的玻璃擬態風格，幫我生成一張 Landing Page 的設計圖」

光球會記住搜尋到的知識，並將其應用在後續的創作任務中。
