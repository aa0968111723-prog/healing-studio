### ②全狀態
- **載入**（`listQ.isLoading`）：網格 **6 張 `.skel`**（`h-28 rounded-xl`）；計數「…」。
- **空/回退**（`!isLoading && items.length===0`）：顯示**內建精選方法論 fallback**（`METHODOLOGY_DOCS` 6 篇），上方小字「（learnHub 暫無資料，顯示內建精選方法論）」。**不顯示空白**——這是刻意的優雅降級（cron 未跑/DB 不可用時仍有內容）。
- **錯誤**：`retry:false`，失敗即走 fallback（同空態）。
- **長內容（80 篇）**：搜尋 + 分類 + 難度三重收斂；`list` 帶 `limit:60, offset:0`（一次最多 60，未來可加分頁/載入更多）。
- **權限**：`learnHub.list`/`learnHub.categories` 為 **public**，無門檻。

### ③進入＆離開條件
- 進入：`.subtabs`「學習中心」、`/learn/docs`、`?sub=hub`、舊 `/tutorial-overview` redirect。
- 離開：切分頁；（建議）點文件卡→閱讀抽屜/頁（沿用既有 LearnHub 詳情）。

### ④分支與決策
- 分類 chip 選中：`category=key`（空＝全部）→ 重抓 `list`；分類數量來自 `categories()`。
- 難度切換：映射 enum 傳 `list`。
- 搜尋：傳 `list` 的 `search`（trim 後；空則 undefined）。
- 「匯入文件」「新增文件」（盤點有此二鈕）：本期維持走既有 LearnHub 寫入頁，**不在富 shell 重造**；可在標題列放 `.btn.sm`「新增/匯入」連去既有頁（內容治理在 `/settings` ContentTab 也有入口）。

### ⑤microcopy（zh-TW）
標題「學習中心 LearnHub」｜副標「方法論與教學文件，同時餵 RAG 與供人閱讀」｜計數「{n} 篇」｜搜尋「搜尋文件…」｜難度「全部難度」｜fallback「（learnHub 暫無資料，顯示內建精選方法論）」｜卡片難度標「{難度} · {n}分」（fallback 顯示閱讀分鐘）。

### ⑥對回真實 route/procedure
- `learnHub.list({ search?, category?, difficulty?, limit, offset }) → { items[], total }`（**public**，`retry:false`、`staleTime:60_000`）。
- `learnHub.categories() → { [category]: count }`（**public**，`staleTime:300_000`）。

## B. 積分 ・ API 用量

### ①畫面結構與佈局
雙欄（`grid lg:grid-cols-[minmax(260px,1fr)_1.6fr] gap-4`，窄螢幕收單欄）：

**左欄 · 餘額卡**（`.card.pad`）：
- eyebrow「`Coins` 方案 · 積分」。
- 大數字（`text-4xl`，`--f-display`）＝剩餘積分；**< 120 時轉 `--bad`（紅，告警）**，否則 `--gold`（琥珀）。下方「可用積分 · pts」。
- **已用比例條**（`.usagebar`/`.ub`/`.ub i` 或 `<Progress>`）：左「已用比例」右「{usedPct}%」。
- 高耗模型（有 `topModel` 才顯示）：「近 30 天高耗模型：**{topModel}**」。
- **取得方式塊**（實站；`--surface-2` 底，小字清單或 `.tag` 列）：「註冊 **+50**／分享資產 **+2**／分享模型 **+3**／管理員加分」。標題「如何取得積分」。
- **安全保障塊**（`--surface-2` 底，小字）：「先扣後生成（**原子**）· 失敗全額退還 · 最小 1 pts / 安全上限 500 pts · 永久有效，不需信用卡。」
- **退還機制表**（實站；`.listrow` 風小表，兩欄「情境 → 處置」）：
  | 情境 | 處置 |
  |---|---|
  | 安全檢查未通過 | **全額退還** |
  | 圖像生成 API 錯誤 | **全額退還** |
  | 影片生成 API 錯誤 | **全額退還** |
  | 音樂生成 API 錯誤 | **全額退還** |
  | 語音生成 API 錯誤 | **全額退還** |
  > 呼應「先扣後生成（原子）」：扣點與生成是原子操作，任一失敗即整筆退回，使用者不承擔失敗成本。「不需要信用卡，不涉及任何真實金錢交易」（盤點原文）。

**右欄 · 用量紀錄卡**（`.card.pad`）：
- 標題「`Receipt` 用量紀錄」＋ mono 副標「api_usage_logs · ai_usage_events」。
- **成本概覽**（3 個 `MiniStat`）：本期請求 `totalRequests`／本期成本 `$totalCost.toFixed(3)`／剩餘配額 `remaining`。
- **用量列表**（`max-h-72 overflow-auto divide-y`）：每列＝日期（w-24，`--muted`）＋類型·模型（flex-1 truncate）＋成本（`--gold`，`$x.xxx`，`tabular-nums` 右對齊）。
- 底部跨連結（`--muted` 小字）：「`TrendingUp` 全站供應商用量分析在 /settings → 管理後台 → 成本金流（admin）。」

### ②全狀態
- **載入**：餘額大數字 `.skel`（h-12 w-32）；用量列 4 條 `.skel`（h-8）。
- **空（無紀錄/未登入）**：用量列區「尚無用量紀錄（或未登入）。」；餘額顯示 `0`/`—`。
- **錯誤**：`retry:false`，失敗→顯示 `—`，不報錯彈窗。
- **長內容**：用量列 `max-h-72` 內捲；`myUsageLogs({limit:20})` 限 20 筆（可加「載入更多」，非本期）。
- **權限**：`credits.myBalance`/`dashboard.myStats`/`dashboard.myUsageLogs` 皆 **protected**——未登入時優雅顯示 `—`/「（未登入）」，不阻斷頁面。`credits.pricingCatalog` 為 public（定價可公開）。

### ③進入＆離開條件
- 進入：`.subtabs`「積分」、`/learn/credits`、`?sub=credits`、舊 `/credits` redirect。
- 離開：切分頁；底部連結 → `/settings?sub=admin`（成本金流，需 leader/admin）。

### ④分支與決策
- 餘額顏色分支：`remaining < 120` → `--bad`（提示快用完），否則 `--gold`。
- 成本來源優先序：`b.remaining ?? stats.remainingGenerations ?? 0`；`usedPct` 來自 `b.usedPct`。
- **不提供「儲值/扣點」按鈕**：扣點＝伺服器內部（`credits` 無 `spend`）；儲值走 `plans.*`/subscription 流程（盤點：平台積分不涉及真實金錢，「不需要信用卡」）。本頁是**唯讀帳務檢視**。
- **取得方式 / 退還機制＝說明性文案（唯讀）**：兩塊都是固定政策展示，不是互動表單。取得積分由真實事件觸發（註冊 +50 為新帳號 grant；分享資產 +2 經 `/assets`/`featured_showcase` 分享；分享模型 +3 經模型分享；管理員加分＝後台 `admin.updateQuota`）——本頁只**呈現規則**並可在餘額變動時 toast「+{n} 積分：{原因}」。退還在生成失敗鏈自動發生（先扣後生成原子性），本頁據實顯示，不提供手動退款鈕。
- **LangSmith 去向**：實站 dashboard 第三籤 LangSmith 已移 `/settings → 觀測`；本頁底部跨連結指過去（不在 `/learn` 重做 LangSmith）。

### ⑤microcopy（zh-TW）
eyebrow「方案 · 積分」｜「可用積分 · pts」｜「已用比例」/「{n}%」｜「近 30 天高耗模型：{model}」｜取得「如何取得積分」/「註冊 +50／分享資產 +2／分享模型 +3／管理員加分」｜安全保障「先扣後生成（原子）· 失敗全額退還 · 最小 1 pts / 安全上限 500 pts · 永久有效，不需信用卡。」｜退還機制表「情境 → 處置」：「安全檢查未通過 → 全額退還」「圖像/影片/音樂/語音生成 API 錯誤 → 全額退還」｜餘額變動 toast「+{n} 積分：{原因}」｜「用量紀錄」｜MiniStat「本期請求」「本期成本」「剩餘配額」｜空「尚無用量紀錄（或未登入）。」｜跨連結「全站供應商用量分析在 /settings → 管理後台 → 成本金流（admin）。」/「AI 監控（LangSmith）已移至 /settings → 觀測。」

### ⑥對回真實 route/procedure
- `credits.myBalance() → { remaining, topModel, totalSpentPoints, usedPct }`（**protected**）。
  > ⚠ 校正：`credits` 僅 `myBalance`/`pricingCatalog`；**無 `spend`/`topUp`**（扣點伺服器內部，儲值走 `plans.*`）。用量寫入＝`apiUsage.upsert`（admin/伺服器側），**非前端 procedure**。
- `dashboard.myStats() → { remainingGenerations, totalRequests, totalCost, recentLogs[], modalityBreakdown[], dailyTrend[] }`（**protected**）。
- `dashboard.myUsageLogs({ limit }) → 個人用量列`（**protected**）。
- `credits.pricingCatalog() → 各模型定價`（**public**）。
- 全站供應商分析（admin）：`apiUsage.overview`/`usageByProvider`/`billing`/`deepCost`（在 `/settings` 管理後台，見 `/settings` 包）。
- **取得/退還＝展示文案**：取得規則（+50/+2/+3/管理員加分）與退還機制（安全檢查未過、圖/影/音/語音 API 錯誤→全額退還）是固定政策說明，**無專屬前端 procedure**；退還由伺服器在生成失敗鏈自動執行（先扣後生成原子性，呼應 `generate.recordGenResult` 回寫點），餘額由 `credits.myBalance` 反映。
- **dashboard 三籤對映**：使用統計＝`dashboard.myStats`／積分帳戶＝`credits.myBalance`＋`dashboard.myUsageLogs`／**LangSmith＝`/settings → 觀測` 的 `langsmith.status`**（不在 `/learn`）。

# 第三部分 · 情報新聞（NewsPanel）

> 分頁 key：`news`｜canonical：`/learn/news`、`/learn?sub=news`
> 對映盤點：站內**無獨立 `/news`**，新聞流在 `/learn`（AI 新聞分類 5 篇）＋模型情報專區。`/social` 的「時事選題」**經脊椎讀此份 `news`**，不另開頁（架構 §1.5.4）。

## C. 情報新聞

### ①畫面結構與佈局
單張 `.card.pad.space-y-4`：
- **標題列**：左「`Newspaper` 情報新聞」＋ mono 副標「news_articles · sense（/social 時事選題經脊椎讀此份）」；右 `.pill`「{n} 則」（載入「…」）。
- **新聞列表**（`space-y-2`）：每則為可點外連列（`.listrow`/`a`，`target=_blank`）：頂行＝`Newspaper` 小圖＋標題（`<b>` 風）＋外連 `ExternalLink`（有 url 才顯示）；下行（`--muted`）＝來源 · 日期 · #標籤。

> 欄位容錯：標題 `title??headline`；來源 `source??publisher??category`；時間 `publishedAt??ts??createdAt`；標籤 `tag??category`；連結 `url??link??"#"`。

### ②全狀態
- **載入**：5 條 `.skel`（h-16 rounded-lg）。
- **空**：「目前沒有情報（news 來源未設或 DB 不可用）。」——誠實標明原因（後端 DB 不可用時優雅回 `{items:[]}`）。
- **錯誤**：`retry:false`，失敗→空態文案。
- **長內容**：`list({limit:20})` 限 20；後端支援 `cursor` 可加「載入更多」（非本期）。
- **權限**：`news.list` 為 **public**，無門檻。

### ③進入＆離開條件
- 進入：`.subtabs`「新聞」、`/learn/news`、`?sub=news`。
- 離開：切分頁；點新聞→新分頁外連（不離開 shell）。

### ④分支與決策
- 列表來源相容陣列或 `{items[]}`（`Array.isArray(data)?data:data.items`）。
- 連結為 `#` 時不顯示外連圖示、不可點（避免死連結）。
- **跨 shell 約定**：`/social` 時事選題**不 import 本頁**，而是脊椎讀同一 `news.list` + 代理層產生選題建議，呈現在 social 介面。本頁是 news 的「人看」入口。

### ⑤microcopy（zh-TW）
標題「情報新聞」｜副標「news_articles · sense（/social 時事選題經脊椎讀此份）」｜計數「{n} 則」｜空「目前沒有情報（news 來源未設或 DB 不可用）。」｜列 meta「{來源} · {日期} · #{標籤}」。

### ⑥對回真實 route/procedure
- `news.list({ limit, cursor?, category? }) → { items[], nextCursor }`（**public**，`retry:false`、`staleTime:120_000`）。
  > ⚠ 校正：情報清單走 `news.list`，**不是** `sense.feed`；`sense` 僅 `inferIntent`（無 `research`/`feed`）。
