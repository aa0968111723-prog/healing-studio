## A. 統計卡（StatCard ×4）

### ①畫面結構與佈局
頂部一排 4 張統計卡（`grid-cols-2 md:grid-cols-4 gap-3`），每張 `.card.pad`：左上小圖示＋標籤（`--muted`，`--f-mono` eyebrow 風格可選），下方大數字（`text-2xl`，`--ink`，`--f-display`）。

| 卡 | 圖示 | 標籤 | 值來源 |
|---|---|---|---|
| 1 | `Cpu` | 模型總數 | `meta.total ?? models.length`（**115**） |
| 2 | `Sparkles` | 廠商 | 從回傳推導的 distinct provider 數 −1（去 `all`）（**~35**） |
| 3 | `Sparkles` | 精選 | `models.filter(featured).length`（**~26**） |
| 4 | `ShieldCheck` | 已查核覆蓋率 | `meta.coverage`（0–1 → `%`，或已是 % 直接顯示）（**100%**） |

> 覆蓋率換算：`coverage ≤ 1` 時 `×100` 取整加 `%`；否則直接取整加 `%`。無值顯示 `—`。

### ②全狀態
- **載入**：四卡值位顯示骨架或 `—`（`q.isLoading` 時 `meta` 為空，值落 `models.length=0`→顯示 `0`/`—`）。建議載入時數字位放 `.skel`（寬 32、高 28）。
- **空/錯誤**：query 失敗（`retry:false`）→ `meta` 空，卡顯示 `—`；不報錯（清單區另有回退提示）。
- **長內容**：不適用（固定 4 卡）。
- **權限**：`aiModels.list` 為 **public**，無需登入。

### ⑥對回真實 route/procedure
- `aiModels.list({ modality, provider, tier }) → { models[], meta{ total, verifiedCount, staleCount, coverage, lastResearchAt } }`（**public**，無金鑰回退 baseline catalog）。
- `meta` 還含 `verifiedCount`/`staleCount`（供 `/settings` 內容治理用，見 `/settings` 包 `03` ContentTab）。

## B. 自動研究卡（盤點 §3-12，建議補上）

> 盤點截到「自動研究卡」：排程已啟用・每天 03:30・累積 2 輪；按鈕「只刷新過期(115)」「手動執行完整研究」；覆蓋率 100%／已驗證待補 0／上次研究 11 小時前（2026/06/05 11:30）／上次耗時 18 秒。P6 `AIModelHubPanel` 目前**只在篩選列右側顯示「上次研究 {time}」**；本節把完整自動研究卡規格化為**建議增強**（同 procedure 家族，純加法）。

### ①畫面結構與佈局
統計卡下、五腦指派上，一張 `.card.pad`（可摺疊）：
- 左：`🔁 自動研究`＋狀態 `.pill.ok`「排程已啟用」＋說明「每天 03:30・累積 {rounds} 輪」。
- 中：三個 mini 指標（`.tag` 或 `MiniStat`）：覆蓋率 `{coverage}%`／已驗證待補 `{staleCount}`／上次研究 `{lastResearchAt 相對時間}`（hover 顯絕對時間）。
- 右：兩顆按鈕——`.btn.sm`「只刷新過期({staleCount})」、`.btn.primary.sm`「手動執行完整研究」。

### ②全狀態
- **載入**：指標 `—`；按鈕 disabled。
- **空**：無排程→狀態 `.pill.mute`「排程未啟用」，按鈕「設定排程」。
- **執行中**：按下「手動執行完整研究」→ 按鈕轉 `.dots`「研究中…」，**走 `<BackgroundTasksContext>` 長任務輪詢**，完成 toast `.toast.ok`「完整研究完成・{n} 個模型已更新・耗時 {s}s」。
- **錯誤**：toast `.toast.bad`「研究失敗（{httpcode}）・稍後重試」；覆蓋率不變。
- **權限**：`runDiscovery`/`refreshStale` 為 **protected**（多半 admin/排程觸發）；非 admin 看得到狀態但按鈕 disabled＋tooltip「需管理員」。
- **長內容**：不適用。

### ④分支與決策
- 「只刷新過期」：僅對 `staleCount>0` 啟用；`=0` 時 disabled＋label「無過期模型」。
- 完成後 `utils.aiModels.list.invalidate()` 重抓，統計卡與網格同步刷新。

### ⑥對回真實 route/procedure
- `aiModels.runDiscovery()`／`aiModels.refreshStale()`／`aiModels.refreshAll()`／`aiModels.refreshOne({id})`／`aiModels.researchStats()`／`aiModels.setSchedule({...})`（GitNexus §11 確認存在）。
- 排程資訊（每天 03:30、累積輪數、上次耗時）來自 `aiModels.researchStats()` 或 `meta`。

## C. 五腦指派（BrainAssignment）

### ①畫面結構與佈局
一張 `.card.pad`，標題「🧠 五腦指派」＋ mono 副標「`user_ai_brain · agent_model_picks`」。下方 `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-3`，**五個腦角色卡**（`.modelcard` 風格）：

五腦（`learnContent.BRAIN_ROLES`，順序固定）：**決策腦／研究腦／長上下文腦／感知腦／生成腦**。

每張腦卡：
- 頂列：角色名（`<b>`）＋右側 `.pill`「{n} 可選」（該腦可指派的合格模型數）。
- 下方：`<select>`（`.input` 風格）下拉，選項＝該腦合格 modality 的模型清單。
- 已指派態：選定後該卡套 `.modelcard.assigned`（黏土淡底＋柔邊），下拉顯示目前指派模型。

**合格 modality 對照（`BRAIN_ELIGIBLE_MODALITY`，前端篩選用）**：

| 腦 | 合格 modality |
|---|---|
| 決策腦 | `llm`, `text` |
| 研究腦 | `search`, `llm`, `text` |
| 長上下文腦 | `llm`, `text`, `embed` |
| 感知腦 | `image`, `video`, `embed` |
| 生成腦 | `image`, `video`, `audio` |

### ②全狀態
- **載入**：models 未到→各腦「0 可選」、下拉 disabled、placeholder「載入中…」。
- **空**：某腦無合格模型→下拉 disabled，唯一選項「無可指派模型」，pill「0 可選」。
- **指派中**：`recordPick.isPending` → 全下拉 disabled＋卡下方 `.dots`「記錄中…」（`Loader2` spin）。
- **成功**：toast `.toast.ok`「已記錄五腦指派」；該腦卡轉 `.assigned`。
- **錯誤/未登入**：toast `.toast.bad`「指派失敗（需登入）」；下拉還原。
- **權限**：`agentModelPicks.recordPick` 為 **protected**——未登入可看清單與下拉，但送出回 401→toast。
- **長內容**：合格模型多時下拉原生捲動即可。

### ④分支與決策
- 選擇模型 onChange → 從 eligible 找回該 model → `recordPick.mutate({ modality, modelId, source:"manual" })`（input 寬鬆 `as any`，不與後端 enum 緊耦合）。
- `source:"manual"` 標記人工指派（相對自動推薦）。
- 指派成功後**可跨 shell 生效**：脊椎 `user_ai_brain` 更新，`/video`/`/social` 生成派工讀此偏好。

### ⑤microcopy（zh-TW）
標題「🧠 五腦指派」｜副標「user_ai_brain · agent_model_picks」｜pill「{n} 可選」｜placeholder「選擇模型…」/「無可指派模型」｜進度「記錄中…」｜成功「已記錄五腦指派」｜失敗「指派失敗（需登入）」。

### ⑥對回真實 route/procedure
- `agentModelPicks.recordPick({ modality, modelId, source }) → ok`（**protected**）。
  > ⚠ 校正：**不是** `agentModelPicks.assign` / `aiModels.assignBrain`（皆不存在）。真實名＝`recordPick`（`03_code_reality_notes` §6.2）。
- 相關：`agentModelPicks.markAcceptance`／`getPreferredForModality`／`getPreferredByModalities`／`getRecent`（可用於顯示「目前指派」回填下拉）。

## D. 篩選列 + 模型網格（核心瀏覽器）

### ①畫面結構與佈局
一張 `.card.pad.space-y-3`：

**標題列**：左「`Cpu` 模型庫 / 願望清單」＋小字計數「{visible.length} / {meta.total} 個」（載入時「載入中…」）；右「上次研究 {lastResearchAt 本地時間}」（有值才顯示，`--muted-2`）。

**篩選列**（`flex flex-wrap gap-2`）：
- 模態 `<select>`（label「模態」）：`all`/`llm`/`image`/`video`/`audio`/`search`/`embed`/`agent`（顯示「全部」當 all）。
- 廠商 `<select>`（label「廠商」）：`all` + 從回傳推導的 distinct provider（排序）。
- 層級 `<select>`（label「層級」）：`all`/`frontier`/`balanced`/`lightweight`/`open-source`。
- 搜尋框（`.input` + 左內嵌 `Search` 圖示）：placeholder「搜尋模型 / 廠商…」，**前端即時過濾** label+provider。

**模型網格**（`grid-cols-2 md:grid-cols-3 lg:grid-cols-4 gap-3`）：每張 `.modelcard`（`hover:bg-muted/40`，建議套 `.modelcard:hover` 抬升）：
- 頂列：模型名（`<b>`，`leading-tight`）＋右側精選 `.pill`/`Badge`「精選」（`featured`/`isFeatured` 為真才顯示）。
- meta 行（`--muted`）：`{provider} · {modality} · {tier}`（缺項省略）。
- 脈絡行（有 `contextTokens`/`contextWindow` 才顯示）：「脈絡 {n.toLocaleString()} tok」。

> 欄位讀取容錯：`field(m, "label","name","modelId","id")`、`field(m,"provider")`、`field(m,"modality")`、`field(m,"tier")`、`field(m,"featured","isFeatured")`、`field(m,"contextTokens","contextWindow")`——後端欄名不一致時逐一退讓，**實作沿用此 `field()` 容錯**。

### ②全狀態
- **載入**（`q.isLoading`）：網格放 **8 張 `.skel`**（`h-24 rounded-xl`）；標題計數「載入中…」。
- **空（無符合）**：篩選/搜尋後 `visible.length===0` → 網格內整列置中 `--muted`「無符合條件的模型。」（不換成全頁空態，保留篩選列）。
- **空（完全無資料）**：`models.length===0` 且非載入 → 同上文案；統計卡顯 `—`。
- **錯誤**（`q.isError`）：篩選列下方行內提示（`RefreshCw` 圖示＋`--bad`）「讀取模型清單失敗，已回退 baseline。」清單仍渲染 baseline（後端 public 會回退）。
- **長內容（115）**：靠模態/廠商/層級三級篩選 + 搜尋收斂；網格自動換行不分頁（115 卡瀏覽可接受，未來可加虛擬捲動，非本期）。
- **權限**：全 public，無門檻。

### ③進入＆離開條件
- 進入：點 `.subtabs`「模型情報」、深連結 `/learn/ai-models`、`?sub=models`、舊 `/ai-models-hub` redirect。
- 離開：切其他分頁（`?sub=` 改）；點願望清單→ `/learn/model-wishlist`（re-home）；（建議）點模型卡→詳情抽屜（見 E）。

### ④分支與決策
- 篩選（模態/廠商/層級）走**後端 input**（`aiModels.list` 重抓）；搜尋字串走**前端即時過濾**（不重抓）——分流明確：粗篩交後端、細找在前端。
- 廠商下拉動態：`providers = ["all", ...distinct(models.provider).sort()]`，隨當前回傳變化。
- 精選優先：可選將 `featured` 卡置頂或加金邊（`.modelcard` + `--gold-soft` 邊）；非必要。

### ⑤microcopy（zh-TW）
標題「模型庫 / 願望清單」｜計數「{n} / {total} 個」/「載入中…」｜label「模態」「廠商」「層級」｜select「全部」｜搜尋「搜尋模型 / 廠商…」｜精選「精選」｜脈絡「脈絡 {n} tok」｜錯誤「讀取模型清單失敗，已回退 baseline。」｜空「無符合條件的模型。」｜「上次研究 {time}」。

### ⑥對回真實 route/procedure
- `aiModels.list({ modality, provider, tier }) → { models[], meta }`（**public**；`retry:false`、`staleTime:60_000`）。
- 模態枚舉（前端常數）：`all/llm/image/video/audio/search/embed/agent`；層級：`all/frontier/balanced/lightweight/open-source`。
- 相關：`aiModels.getById({id})`（詳情）、`aiModels.discoveries()`（新發現）。

## E. 模型詳情（建議增強：點卡開抽屜）

> P6 目前模型卡為唯讀摘要。盤點顯示模型情報區可展開詳情（廠商/模態/定價/可用性/脈絡）。本節規格化**點卡開右側抽屜**（純加法，用既有 `getById`）。

### ①畫面結構與佈局
點 `.modelcard` → 右側 `Sheet`/抽屜（沿用脊椎抽屜風格）：
- 頭：模型名（`--f-display`）＋ provider／modality／tier `.pill` 群＋精選標。
- 區段：**可用性**（見 F）｜**定價**（`credits.pricingCatalog` 對應該模型，「每張/每千 tok {pts}」）｜**脈絡窗**｜**廠商連結**（`.source` 風格，`--info` URL）｜**指派狀態**（是否已是某腦的選擇）。
- 底部行動：`.btn.primary`「指派到…腦」（開五腦下拉）、`.btn`「加入願望清單」（→ model-wishlist）。

### ②全狀態
- **載入**：抽屜骨架。
- **空**：`getById` 無此模型→「找不到模型資料」+ 關閉。
- **錯誤**：行內 `--bad`「載入詳情失敗」+ 重試。
- **權限**：定價 public；指派 protected（未登入→「需登入」）。

### ⑥對回真實 route/procedure
- `aiModels.getById({ id }) → model`；`credits.pricingCatalog() → 各模型定價`（**public**）；指派沿用 C 的 `agentModelPicks.recordPick`。
