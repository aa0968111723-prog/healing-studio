## 1. `/learn` 一句話定位

`/learn` 把分散在線上的 **學習中心（LearnHub 434KB）／模型情報（`/ai-models-hub`）／積分（`/dashboard?section=credits`）／API 金鑰／情報新聞／研究代理** 收進**同一個獨立 shell、一個富首頁、六個分頁**。它**不造新引擎**——所有分頁打的都是 GitNexus 校正後的**既有 tRPC procedure**；研究面板預設 `mock`（零金鑰即可 demo），接真實只換一行旗標。

> 與其他 shell 的分界：`/learn` 是「**讀**知識與帳務」的地方，不做創作/生成派工（那是 `/video`、`/social`）。它治理的是「研究結果、模型情報、用量」，這些**寫進脊椎**後其他 shell 自然讀得到——例如 `/social` 的「時事選題」是**經脊椎讀本 shell 的 `news`**，不開 `/learn` 頁面（架構 §1.5.4）。全站治理（權限/旗標/管理後台）在 `/settings`，不在這。

## 2. 設計契約 · Token 契約（引用 `theme.css`，不自造）

**單一真實來源＝`AI-Director-UIUX設計/00_設計系統/theme.css`**（rev.L1，亮色「暖光 Claude」）。本 shell 所有顏色、字級、間距、圓角、陰影、動效時長**一律引用該檔 CSS 變數**，不得在 `shells/learn/*` 內寫死 hex 或另立色票。`theme.css` **已內含 `/learn` 專屬區塊（§8 LEARN）**，直接用其 class。

### 2.1 視覺定調

亮色版面：暖米白分層表面（`--paper`/`--bg`/`--surface`）＋黏土／珊瑚橘主強調（`--clay`）＋蜜金次強調（`--gold`），大量留白、柔和大圓角、克制細邊框、標題帶 Fraunces serif 質感、內文 Inter/Noto Sans。資訊密度高的瀏覽/帳務頁要「安靜」，靠層次與留白而非邊框與色塊。

## 6. 全域狀態與跨分頁 UX（所有分頁共用）

實作每個分頁時，下列六態都要落地（六段格式的 ②）：

1. **載入（loading）**：用 `.skel`（shadcn `<Skeleton>`）骨架；卡片區骨架數對齊正式內容（如模型 8 卡、新聞 5 列、文件 6 卡）。標題列右側計數顯示「載入中…」或「…」。
2. **空（empty）**：`.state` 置中＋圖示＋一句說明（誠實標明原因，如「news 來源未設或 DB 不可用」）。不可空白頁。
3. **錯誤（error）**：`.state.error` 或行內 `--bad` 提示；**多數 query 設 `retry:false`**，失敗即顯示「已回退 baseline／需登入」而非無限轉圈。研究面板另有專屬錯誤態＋重試（見 `03`）。
4. **長內容（long）**：列表用 `max-h-* overflow-auto`（用量列 `max-h-72`、使用者列 `max-h-[28rem]`）；模型/文件用 grid 自動換行；搜尋/篩選即時收斂，避免一次塞 115。
5. **權限（permission）**：未登入時 `protectedProcedure`（如 `credits.myBalance`/`agentModelPicks.recordPick`）優雅顯示 `—` 或「需登入」toast，不阻斷其他公開內容（`aiModels.list`/`news.list`/`learnHub.*` 為 public，無金鑰可讀）。admin-only 內容（平台金鑰狀態）對非 admin **完全不請求、不顯示**（RBAC，見 `03`/`/settings` 包）。
6. **部分降級（degraded）**：研究 Sonar→Brave-only→無 grounding 掛橫幅；模型清單讀取失敗回退 baseline catalog；learnHub 無資料回退內建精選方法論（`METHODOLOGY_DOCS`）。

**跨分頁通則**：
- **頂部標題**：`📚 學習文件系統` + 副標「學習中心 · 模型情報（115）· 研究代理（Sonar+Brave）· 積分 / API · 情報新聞」。
- **窄螢幕**：`.subtabs` 可換行（`flex-wrap`）；分頁內三欄/雙欄收成單欄（≤780px，對齊 `theme.css` §14）；底部 `.mnav`（脊椎提供）。
- **a11y**：分頁 `role=tablist`，鍵盤左右切換；焦點環走 `--clay-ring`；`prefers-reduced-motion` 關掃光/轉圈位移（保留狀態切換）。
- **數值格式**：千分位 `toLocaleString("zh-TW")`；日期 `toLocaleDateString/String("zh-TW")`；積分以整數 `pts`、成本以 `$x.xxx`。
