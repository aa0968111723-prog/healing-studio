## 1. 素材來源選擇器 SourceSelector（多模態素材創作）

**版面**：單卡置中（max 980）。頂部 `Seg` 三選一：**站內生成｜上傳自有｜外部 AI 帶入**；中段為該路徑面板；底部「專案素材（最新）」清單 ＋「前往打包初剪 →」。

### 1.A 站內生成
| 項 | 規格 |
|---|---|
| 欄位 | 綁定鏡頭 select（idle 鏡頭 S0X，可「不綁定 · 自由素材」）· 模型 select（Z-Image-Turbo/FLUX/Qwen-Edit）· 提示詞 textarea（**必填**）· 「智慧編譯提詞」（補風格 token，同 `compilePrompt`） |
| 驗證 | 空提示詞 → 送出時擋下＋inline 錯誤「提示詞不可為空」 |
| 流程 | **估算（estimating）→ 先扣後生成（generating，掃光＋jobchip `jobType image ✅ · processing`）→ done（縮圖＋seed＋provider）**；done 旁掛 `SaveToVault` 與「再生一張」 |
| 狀態 | idle／estimating／generating／done／**error**（HTTP 504＋回退鏈 hf→gemini→fal＋已全額退還＋重試）／**積分不足**（擋下→/learn） |
| procedure | `generate.estimateCost → submitStudioJob → jobStatus → recordGenResult` ✅；底層 `imageStudio.<model>` ✅；估成本另可 `director.estimateSegmentCost` ✅；非同步統一入口 `generate.submitMultimodalAsync` ✅（回 `{jobId,requestId}`） |
| 存庫 | **✅ 自動存草稿＝真實行為**：postGenActions 完成時 **prompt ≥4 字即自動寫 `prompt_library`**（§8A）——UI 的「自動存草稿」Toggle 對映此行為；手動「＋存入提示詞庫」＝顯式 `promptLibrary.create` |
| 資料 | `digital_asset_library`（sourceStudio: `image`；綁定鏡頭時同步把該 shot 標 done） |

### 1.B 上傳自有
| 項 | 規格 |
|---|---|
| 畫面 | Dropzone（點擊/拖放）＋格式說明 |
| 格式限制 | **jpg / png / webp / mp4 / mov / mp3 / wav · 單檔 ≤ 500MB**；不符 → 錯誤態（列原因＋支援清單＋重試） |
| 狀態 | empty／**uploading**（進度條：驗證型別→雜湊→入庫）／done（pill「已入資產庫·我的」）／**error**（格式不支援） |
| procedure | ⚠ **正式上傳 procedure 待補（歸後端）**——現況走 R2/S3 直傳；入庫落 `digital_asset_library`；`assets.*` 讀取 ✅ |
| sourceStudio | ⚠ 真實 enum 現值＝`image/video/audio/pro/creative/director/background/webhook/suno/replicate/unknown`（§8A）——**無 `upload` 值**；上傳素材的 sourceStudio 標記為**待補新值**（varchar32 可加法擴充），過渡可落 `unknown`＋meta 註記 |

### 1.C 外部 AI 帶入
| 項 | 規格 |
|---|---|
| 畫面 | URL input（Midjourney/SD/其他）＋「帶入」 |
| 驗證 | 需 `http(s)://` 前綴；不符 → inline 錯誤；（demo：URL 含 `fail` 走失敗路徑） |
| 狀態 | idle／fetching（驗證→轉存→入庫）／done（pill「已帶入」＋**warn pill「外部來源 · 未經站內估算」**）／**error**（404，建議改上傳） |
| 規則 | 外部素材**不扣積分、不經站內估算**；進分鏡仍走**確認門** |
| procedure | ⚠ **匯入 procedure 待補（歸後端）**；sourceStudio 同 1.B——**無 `external` 值**，標記**待補新值**（過渡 `webhook`/`unknown`＋meta） |

**權限**：無生成權→ 路徑 A 鎖定態；唯讀協作者→ 三路徑皆唯讀提示。

## 2. 打包素材 ＋ 簡易初剪 rough-cut

**版面**：工具列（▶ 預覽／📦 匯出打包／真實面 tip）→ 確認門警示列（如有未核准段）→ **預覽窗**（大畫面＋playhead 進度）→ **影像軌**（clip 列：縮圖｜S0X＋標題＋核准 pill｜in/out 裁切（±0.5s，**有效長 ≥0.5s**）｜**音軌配對 select**（配樂/旁白/環境音）｜↑↓ 排序｜✕ 移出）。

**素材來源**：done 鏡頭自動進軌（同 seed 縮圖）；上傳/外部素材以 `EXT` 進軌；新增素材→時間軌自動重建。

**確認門整合（鐵則）**：clip 內含**未核准**鏡頭 → 警示列「N 段未核准 — 未核准不跑 i2v／不進打包」＋〔回確認門核准〕〔排除未核准段〕；匯出時硬擋。

**預覽**：逐段播放（高亮目前 clip＋playhead 前進＋預覽窗換幀）；可中停；結束 toast 總長。

**匯出打包**：驗證（非空＋全核准）→ **估算成本 · 先扣後生成**（50 pts，失敗全額退還）→ **exporting**（進度＋jobchip：`background_jobs · jobType zip_export ✅ · processing`）→ **completed**（成品卡：MP4 1080p · N 段 · 總長 · 已寫回資產庫＋timeline〔postGenActions 一次寫 4 處〕＋〔前往確認修改〕）→ 或 **failed**（504＋**斷路器 3 連敗開路（冷卻 10 分）**＋已退點＋重試；卡住 15 分由 reaper 收割、≤3 次自動重試）。成品以 `kind:打包` 入資產庫。

**狀態矩陣**：空軌（EmptyState→去素材步）／編輯中／預覽中／匯出中（processing）／匯出完成（completed）／匯出失敗（failed＋斷路器）／取消（cancelled，預留）／長內容（多 clip 捲動）／未核准警示。

**procedure / 資料對映（✅ 已依深掘回填）**
| 動作 | 真實面 | 狀態 |
|---|---|---|
| 素材箱/入軌 | `assets.*` → `digital_asset_library` | ✅ |
| 配樂/旁白 | `proStudio.textToMusic / soundEffects / elevenLabsTTS / qwenTTS`（音樂引擎吃 brain 預設） | ✅ |
| 打包 job | `background_jobs` · jobType **`zip_export`** ✅ · status `queued→processing→completed/failed/cancelled` | ✅ 表＋enum 已驗（schema.ts:281） |
| job 查詢 | `generate.myJobs`（全部）· `generate.activeJobs`（近 24h＋進行中） | ✅ |
| 重試/取消 | **無 top-level cancel/retry procedure**——重試由 reaper 自動（≤3 次）；前台手動重試鈕列**拍板項** | ⚠ 待拍板 |
| 完成後寫回 | **postGenActions `doPostGenComplete`**：prompt_library＋digital_asset_library＋generation_history＋監控＋封存 | ✅ 樞紐已驗（§8A） |
| 段落編排/成片狀態機（i2v 成片） | `video_generation_sessions`／`video_segment_jobs`／`generateSegment` | ❌ **待補（M3 歸後端）** |
