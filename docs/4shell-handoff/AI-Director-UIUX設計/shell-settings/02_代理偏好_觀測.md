# 第一部分 · 代理偏好（AgentPrefsPanel）

> 分頁 key：`agent`｜canonical：`/settings/agent`、`/settings?sub=agent`
> 對映盤點 §3-14（`/settings/agent`）：預設人格、行為、最近活動。

## A. 代理偏好

### ①畫面結構與佈局
兩張 `.card.pad`：

**(1) 偏好卡**：
- 標題列「`Brain` 代理偏好」＋ mono 副標「agent_preferences · agent_model_picks」。
- **預設導演人格**列（`.setrow` 變體）：左標題「預設導演人格」+ 說明「Calm / Creative / Technical（orbStore 思考球）」；右**三段切換器**（`inline-flex rounded-lg border p-0.5`，三顆按鈕）：平靜／創意／技術。選中套對應**人格三色**（`--persona-calm`/`--persona-creative`/`--persona-technical`，對齊 `theme.css` `.persona .p.on.*`）。
- pending 時下方 `Loader2` spin「更新中…」。
- **六代理層狀態**：eyebrow「六代理層狀態」＋ `grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-3`，6 張小卡（`.modelcard` 風）：每卡＝emoji+名稱（`<b>`）＋右側 `.pill`（可用 secondary／待接 outline）＋下方角色說明（`--muted`）。

**六代理層（`SIX_AGENTS`，順序固定，對映 `learnContent`）**：

| emoji | 名稱 | 角色 | 真實 procedure | 狀態 |
|---|---|---|---|---|
| 🎬 | 導演 AI | 創作對話 · 三人格 | `director.chat` | 可用 |
| 🧭 | 總指揮 | 意圖編排 · 先計畫 | `commander.createIntent` | 可用 |
| 📦 | Context Packet | 壓縮上下文 | `contextPacket.compileProject` | 可用 |
| 🌐 | 研究代理 | Sonar + Brave 引用 | `orbProxy.unifiedSearch` | 待接 |
| 👁 | 感知代理 | 模糊先反問 | `sense.inferIntent` | 可用 |
| 🧮 | 財財（成本） | 先估成本再確認 | `apiUsage` / accountant | 可用 |

**(2) 最近活動卡**：
- 標題「`Activity` 最近活動」。
- 活動列（`max-h-64 overflow-auto divide-y`）：每列＝動作描述（flex-1 truncate）＋狀態 `.pill`（接受/取消/完成/失敗）＋日期（`--muted-2`）。取前 15 筆。

### ②全狀態
- **載入**：人格切換器用 `pref.persona` 預設（`prefQ` 載入後填）；活動卡「載入中…」。
- **空**：活動 0 筆→「尚無活動（或未登入）。」
- **錯誤**：`retry:false`；失敗→人格落預設 `calm`、活動空態。
- **長內容**：活動 `max-h-64` 內捲，取 15 筆。
- **權限**：`agentPreferences.*` 為 **protected**——未登入時人格切換送出失敗 toast「更新失敗（需登入）」、活動空。
- **更新中**：`update.isPending` → 三段切換器 disabled + 「更新中…」。

### ③進入＆離開條件
- 進入：`.subtabs`「代理偏好」、`/settings/agent`、`?sub=agent`。
- 離開：切分頁（人格已即時保存，無草稿）。

### ④分支與決策
- **人格即時 mutation**（非草稿）：點人格 → `update.mutate({ persona })`（input 寬鬆 `as any`，不與後端 schema 緊耦合）→ 成功 toast「已更新代理偏好」+ `invalidate` 重抓。
- 人格三色對映導演 AI 三人格（與 `/video` 導演台一致）：calm=平靜（藍）／creative=創意（黏土橘）／technical=技術（紫）。
- 六代理層為**唯讀狀態展示**（不可在此啟停）；「研究代理」標「待接」對齊 `/learn` 研究 mock-default 現況。
- 活動狀態色：完成/接受→`.pill.ok`；取消→`.pill.mute`；失敗→`.pill.bad`。

### ⑤microcopy（zh-TW）
標題「代理偏好」/「agent_preferences · agent_model_picks」｜「預設導演人格」/「Calm / Creative / Technical（orbStore 思考球）」｜人格「平靜」「創意」「技術」｜「更新中…」/「已更新代理偏好」/「更新失敗（需登入）」｜「六代理層狀態」+ 六層名稱/角色/「可用」「待接」｜「最近活動」/「尚無活動（或未登入）。」

### ⑥對回真實 route/procedure
- `agentPreferences.getPreferences() → 偏好物件`（**protected**）。
- `agentPreferences.updatePreferences(partial) → ok`（**protected**）。
- `agentPreferences.getRecentActivity() → 活動列`（**protected**）。
- 五腦/模型指派在 `/learn` 模型情報分頁（`agentModelPicks.recordPick`）；此處只設人格與展示六代理層。

# 第二部分 · 觀測（ObservabilityPanel）

> 分頁 key：`obs`｜canonical：`/settings?sub=obs`
> 對映開發計畫 §P6「/settings/observability 看 langsmith/process/tasks」＋盤點背景任務。收編 dashboard 的 LangSmith 籤、`/process` ProcessViewer、`/background-tasks`。

## B. 觀測

### ①畫面結構與佈局
依角色三段（langsmith 全員可見、系統概覽/背景任務僅 admin）：

**(1) LangSmith 卡**（全登入者）：
- 標題「`Gauge` LangSmith（AI 監控）」＋右側狀態 `.pill`（已連接 secondary／未設定 outline）。
- 說明「追蹤 LLM 呼叫鏈、延遲、成本（langsmith.status / stats）。未設金鑰時為 no-op。」

**(2) 系統概覽卡**（**僅 admin**）：
- 標題「`ServerCog` 系統概覽」。
- 4 格 `Stat`（`grid-cols-2 md:grid-cols-4`）：總使用者／總生成／總成本（`$x.xx`）／數位資產。

**(3) 背景任務卡**（**僅 admin**；非 admin 顯替代卡）：
- 標題「`Activity` 背景任務」＋ mono 副標「background_jobs」。
- 任務列（`max-h-72 overflow-auto divide-y`）：每列＝標籤（flex-1 truncate）＋狀態 `.pill`（done/completed→secondary、failed→destructive/`--bad`、其他→outline）＋日期。
- 非 admin：替代卡「背景任務 / 系統統計需管理員權限。」

### ②全狀態
- **載入**：LangSmith 狀態 `.skel`（h-5 w-16）；系統概覽 4 格 `.skel`（h-14）；背景任務 4 條 `.skel`（h-8）。
- **空**：背景任務 0 筆→「無背景任務。」
- **錯誤**：`retry:false`；admin query 失敗→等同無資料。
- **長內容**：任務列 `max-h-72` 內捲；`allBackgroundJobs({limit:30})` 限 30。
- **權限（核心）**：`isAdmin = role==="admin"`。`langsmith.status` protected（任何登入者）；`admin.systemStats`/`admin.allBackgroundJobs` **adminProcedure**——非 admin **設 `enabled:isAdmin` 不發請求**，並以替代卡告知需權限。

### ③進入＆離開條件
- 進入：`.subtabs`「觀測」、`?sub=obs`。
- 離開：切分頁；深做→ `/settings/admin/api-usage`（成本）、`/settings/admin/brain-pipeline`（大腦圖）re-home 頁；`/process` ProcessViewer 為脊椎觀測（可連去）。

### ④分支與決策
- LangSmith 連線判定：`ls.connected || ls.enabled || ls.ok` 任一為真→「已連接」否則「未設定」（未設金鑰為 no-op，不報錯）。
- 背景任務狀態色：done/completed→ok；failed→bad；queued/running→outline。
- 系統概覽欄位容錯：`totalUsers??userCount`、`totalGenerations??generationCount`、`totalCost`、`totalAssets??assetCount`。

### ⑤microcopy（zh-TW）
「LangSmith（AI 監控）」/「已連接」「未設定」/「追蹤 LLM 呼叫鏈、延遲、成本（langsmith.status / stats）。未設金鑰時為 no-op。」｜「系統概覽」+ 4 格「總使用者」「總生成」「總成本」「數位資產」｜「背景任務」/「background_jobs」/「無背景任務。」｜非 admin「背景任務 / 系統統計需管理員權限。」

### ⑥對回真實 route/procedure
- `langsmith.status() → { connected/enabled/ok, ... }`（**protected**）；`langsmith.stats({...})`（統計）。
- `admin.systemStats() → { totalUsers/userCount, totalGenerations/generationCount, totalCost, totalAssets/assetCount }`（**adminProcedure**）。
- `admin.allBackgroundJobs({ limit }) → 背景任務列`（**adminProcedure**）。
