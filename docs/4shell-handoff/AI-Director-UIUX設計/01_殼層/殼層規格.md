# AI Director · 共用 App 殼層規格（4-Shell ＋ 脊椎 Chrome）

> **性質**：四殼共用的 app 殼層／脊椎 chrome 規格。引用 `00_設計系統/設計系統.md` 的 token 與元件。
> **心智模型**：**一條後端脊椎，四個各自獨立的前端 shell**——像 Claude 與 Claude Code：不同介面、不同 UX、互不嵌入，但**共用同一帳號、專案上下文與模型**。
> **視覺**：亮色暖光 Claude 質感（見設計系統）。**保留原系統**：class 名稱、版面、路由、功能全保留，只換亮色＋補細節。
> **事實基準**：`AI-Director-模擬`（App.tsx / SpineProvider / chrome/*）＋ `_research/03_code_reality_notes.md`（GitNexus 真實 import 圖）＋ `AI-Director_四大系統架構.md` §1.5/§3。

## 1. 殼層架構（脊椎 + 4 shell）

```
SpineProvider（脊椎・單一實例・四殼共讀寫，不複製）
├─ 專案上下文 active-project（ProjectsContext / useActiveProject）★跨殼不變量
├─ Context Packet（壓成 2k–8k token 精華；contextPacket.compileProject）
├─ 六代理層（Claude · Sonar+Brave · SubQ[待接] · Gemini · HF · 程式）
├─ 數位資產庫總帳 · 團隊 ACL · 確認門 · 排程/筆記 · background_jobs
├─ 全站狀態：provider / faults / theme / persona / credits / flags / toasts / cmdkOpen
└─ 跨殼 chrome：Rail · TopBar · ProjectSwitcher · CommandPalette(⌘K) · Toasts · MobileNav
     │
     ├─ 🎬 VideoShell   /video   （旗艦・三欄 cockpit）
     ├─ 🖼 SocialShell  /social  （社群圖文・另平行工作階段）
     ├─ 📚 LearnShell   /learn   （學習/研究・另平行工作階段）
     └─ ⚙ SettingsShell /settings（治理・另平行工作階段）
```

**邊界鐵則**：一個 shell **不嵌入**另一個 shell 的 UI；要對方資料只透過脊椎（§4）。  
**跨殼不變量**：使用者在任一殼切的 active project 為全站共享；從 `/video` 切到 `/social` 帶**同一專案上下文**（TopBar 的 `Context Xk tokens` 不變）。

### 1.1 真實程式碼錨點（GitNexus 校驗，給工程）
- **拆殼風險低**：`client/src/pages/` 65 頁**跨頁 import = 0**；`DashboardLayout` 只被 `App.tsx` import；僅 5 頁直接用 active-project。重整工作集中在 `App.tsx`（54 路由）＋ `DashboardLayout` 參數化。
- **脊椎單例 provider**（必留脊椎層，不下放）：`ProjectsContext`、`PersonalSettingsContext`、`ThemeContext`、`BackgroundTasksContext`、`AIStateContext`。
- **前置整理**：先打斷 `PersonalSettingsContext ⇄ useMobile` **循環依賴**（改參數注入或下沉 util），再抽 SpineProvider。
- **shell 對映單一真相源**：`shared/appRegistry.ts`（`group` → shell；前後端＋AI 知識同步生效）；`SIDEBAR_GROUPS=[]`、`VISIBLE_DOCK_PAGE_IDS` 換成 4-shell 切換器。
- **抽出順序**（blast-radius）：`/settings` → `/learn` → `/video`（重脊椎）→ `/social`（新建）。

## 3. 脊椎 Chrome 元件規格（含全狀態）

### 3.1 Rail（左側殼切換器，桌機 76px）— class `.rail`
- 結構：`logo`（OrbMark 42，→ `/`）→ 4 殼鈕 `.sw`（Icon `.gi` ＋ 中文 `.lb` ＋ EN mono `.en`）→ `.rail-sp` → 底部 `.mini`（⌘K）。
- 狀態：
  - **作用殼**：`.sw.on`（clay→gold 淡底 ＋ 左側 clay→gold 光條 ＋ clay 文字）；判定 `loc.startsWith(path)`。
  - **hover**：`.sw:hover`（surface-2 底、圖示上移 1px）。
  - **focus-visible**：clay 光環（鍵盤可達）。
  - **feature flag 隱藏**：`social`/`learn` 若 flag off 不渲染（`if(m.flag && !flags[m.flag]) return null`）。
  - **積分不足 badge**：`learn` 在 `credits < 120` 顯示 `.badge`（gold `!`）。
- a11y：每鈕 `aria-current="page"`（作用殼）；圖示 `aria-hidden`，文字為可讀標籤。

### 3.2 TopBar（上 58px）— class `.topbar`
- 結構：麵包屑 `.crumb`（emoji `.ce` ＋ serif 殼名 `.sh` ＋ mono EN `.sub`）｜`ProjectSwitcher`｜`.sp`｜`ProviderChip`｜積分 `.tbtn`（coin＋數）｜⌘K `.tbtn`（OrbMark＋光球＋`kbd`）。
- 狀態：
  - **providerDown**：`.provchip.down`（紅點）→ 點擊去 `/settings/provider`。
  - **lowCredits**：積分 `.tbtn.down`（`credits<120` 轉 bad 紅字）→ 去 `/learn/credits`。
  - **手機 ≤780**：`.hideSm` 隱藏 provider chip 與麵包屑副標。
- 背景：暖白半透明 ＋ `backdrop-blur`（安靜的玻璃感，非厚重）。

### 3.3 ProjectSwitcher（脊椎）— class `.projpill`
- 收合：作用專案 `.pe`emoji ＋ `.pn`名 ＋ `.cf`（`Context X.Xk tokens` ＋ layers 圖示）＋ chevron。
- 展開（`open`）：固定浮層 `.card`；群組標題；每列 `.src`（emoji／名／`type · N 鏡 · N 角色`），作用專案高亮 ＋ check；底「＋ 開新專案」(`createProject`)。
- 狀態：closed / open；空（無專案 → 只有「開新專案」）；長清單（捲動）。
- 真實接點：`creativeProject.list/create/get`；切換 → 重新 `contextPacket.compileProject`。

### 3.4 ProviderChip — class `.provchip`
- `provider`=hf·gemini·fal·mock；`down`（綠點 ok / 紅點 bad，發光環）。點擊 → `/settings/provider`。

### 3.5 CommandPalette（⌘K，跨殼）— class `.cmdk`
- 開：`⌘/Ctrl+K`；關：`Esc` 或點遮罩。鍵盤：`↑/↓` 移動 `.sel`、`↵` 執行。
- 分組：**前往**（首頁/影片/社群/學習/設定）·**代理動作**（排程生成所有就緒鏡 `scheduleGeneration`／重建 Context Packet `contextPacket.compileProject`／研究 i2v 一致性 → `/learn/research`）·**切換專案（脊椎）**·**生成 Provider**·**主題**。
- 狀態：`default` / `empty`（查無指令：顯示「找不到指令 · 試試…」）。
- a11y：`role="dialog" aria-modal`；輸入 `aria-label`；列 `role="option" aria-selected`；focus trap。

### 3.6 Toasts（右下）— class `.toasts` / `.toast`
- `kind`=ok·warn·bad·info；右下滑入；4.8s 自動消失；點擊關閉；`aria-live="polite"`。
- 典型：生成成功（`-N 積分`）／自動回退 provider（`hf → gemini`）／生成失敗（HTTP/錯誤碼）／積分不足／管理回饋。

### 3.7 MobileNav（手機 ≤780 底部）— class `.mnav`
- 影片／社群（flag）／〔中央 clay 光球 FAB → ⌘K〕／學習（flag）／設定；作用 `.on` clay；FAB 上浮 −24。

### 3.8 StateInspector（演示用）— class `.inspector`
- `Seg`：自動／空狀態／載入中／成功／錯誤——強制切換主資料區的四態，交付/驗收用；正式上線可隱藏。

## 6. 進站與離開／四態（殼層層級）
- **進站**：`/` 意圖進站（`onboarding` flag）→ 選意圖卡導到對應殼；或直接進 `/video`。
- **Disabled（flag off）**：被關閉的殼顯示 `.state`（🚫 ＋「此系統未啟用」＋管理員可於 `/settings` 開啟）——示範 feature-flag kill switch。
- **載入**：殼層 `Suspense` fallback = `LoadingState`（「載入系統」）；各殼內主資料區自備四態。
- **錯誤**：殼層級錯誤邊界 → `ErrorState`（標 tRPC 命名空間，如 `director.*`），可重試。
