# 04 · 步驟 S6 — 簡易圖層拼接（layer-compositing UI / `composeLayout`）

> 主場＝`/social/studio` 的「文字排版合成」分頁。把**擴散生成的底圖**與**確定性渲染的文字/元件層**分層疊合成最終單張。
> 🔑 **鐵則**：文字層**不交擴散模型**。擴散模型生不出可靠中文字與精準排版（錯字/糊字/字體不可控）；社群/海報命脈是**文字清晰＋品牌字體正確**。因此 text-layout 採**確定性模板渲染**（HTML/CSS 或 SVG/Canvas，套 brand kit 字體與色票，後端 headless 或前端 `<canvas>` 匯出）。這是 `/social` 相對 `/video` 唯一真正新增的能力，唯一新 method＝**`social.composeLayout`**。

---

## 1. 概念模型（三層 + 插槽）

```
最終單張 = 背景層(擴散/上傳) + 元件層(logo/講師去背/裝飾) + 文字層(確定性渲染插槽)
                │                      │                          │
        backgroundAssetId        asset 元件                 slots:{headline,
        (來自 S4/S5)             (來自 S3/S5 去背)            subhead,body,cta,badge}
                                                              套 brandKit 字體/色/安全邊距
```

**LayoutReq（送 `composeLayout` 的契約）**：
```
LayoutReq {
  templateId,         // block_combos 風格模板 / showcase 版面範本（排版骨架）
  brandKitId,         // 套色票/字體/logo/安全邊距
  slots: { headline, subhead, body, cta, badge },  // 文字插槽（純文字 → 確定性渲染）
  elements: [{assetId, x,y,w,h,rotation,opacity,z}], // 元件層（logo/講師/裝飾）
  backgroundAssetId,  // 底圖（擴散生成或上傳）
  ratioPreset         // 1:1 / 9:16 / A4 ...（主圖比例；多尺寸在 S9）
} → 回 GenJob{ assetId, status, estimatedCost≈0 pts }（合成≈0，仍走確認流程＋記帳保一致）
```

> **三正交層**：`block_combos` 管**生成風格**、`showcase` 範本管**排版骨架**（`templateId`）、`brand_kit` 管**品牌套用**（字體/色/logo/安全邊距）。S6 把三者組成一張可編輯、文字保真的成品。

## 2. 畫面結構與佈局（`/social/studio` · 文字排版合成）

```
┌──────────── /social/studio · 文字排版合成 ────────────────────────────┐
│ chips：類型：海報 · 品牌：療癒誌 · 範本：講座海報-A ✎                   │
│ ┌─ 左：圖層列 ──────┬──── 中：合成畫布 ────┬─ 右：屬性 ──────────────┐ │
│ │ ▦ 文字·標題 ✎🔒👁 │  ┌──────────────────┐ │ 〔選中：文字·標題〕      │ │
│ │ ▦ 文字·副標 ✎🔒👁 │  │  安全邊距虛線      │ │ 文字：春季禪修講座       │ │
│ │ ▦ 文字·內文 ✎🔒👁 │  │  ┌──────────────┐ │ │ 字體：Noto Serif TC▾     │ │
│ │ ▦ 文字·CTA  ✎🔒👁 │  │  │ 春季禪修講座  │ │ │ （限品牌字體）           │ │
│ │ ▣ 元件·logo  🔒👁 │  │  │ 4/20(六) 14:00│ │ │ 字級：48 / 行距：1.3     │ │
│ │ ▣ 元件·講師  🔒👁 │  │  │ [立即報名]    │ │ │ 顏色：品牌主色 ●▾        │ │
│ │ ▤ 背景       🔒👁 │  │  └──────────────┘ │ │ 對齊：⬅⬆⬇➡ ▦網格        │ │
│ │ ──────────────── │  │  logo↘ 安全區內    │ │ 位置：x y / 尺寸 w h     │ │
│ │ [+文字][+元件]    │  └──────────────────┘ │ 不透明度：100%           │ │
│ │ [群組][對齊]      │  比例：海報直幅 ▾      │ 對比檢查：AA ✅          │ │
│ └──────────────────┴────────────────────────┴─────────────────────────┘ │
│ 積分徽章：~0 pts（合成） [預覽] [合成這張 → 入庫] [回 S5 改素材]            │
└──────────────────────────────────────────────────────────────────────────┘
```

**三欄職責**：
- **左·圖層列**：由上到下＝z 由高到低。每層 `✎重命名 / 🔒鎖 / 👁顯隱`，可拖曳重排、群組折疊。`+文字`（新增插槽）、`+元件`（從庫拉 asset）。
- **中·合成畫布**：所見即所得；顯示**品牌安全邊距虛線**、**對齊網格**、**logo 最小尺寸/保留區**輔助線。選中層出現控制把手（移動/縮放/旋轉）。
- **右·屬性面板**：選中層的屬性。**文字層**：文字內容、字體（**限 brand kit 字體**）、字級/行距、顏色（**限品牌色票**）、對齊、位置/尺寸、不透明度、**對比檢查徽章（AA）**。**元件層**：位置/尺寸/旋轉/不透明度/翻轉。**背景層**：可換、可微調濾鏡（轉 S5）。

**品牌約束（顯性）**：
- 字體下拉**只列 brand kit 字體**（標題/內文兩家族）；選非品牌字體被擋並提示。
- 顏色選擇器**只給品牌色票**（主/輔/強調/中性）；自由色被擋（要自由色需先在 `/brand` 擴充色票）。
- logo 縮放到小於最小尺寸 → 紅線警告；移出安全區 → 吸附回安全區或警告。
- 每個文字層即時跑**對比檢查**：與其後方像素對比 < AA → 標 `low_contrast`（可覆寫，記 reason，§01§3）。

## 2'. 全狀態（空 / 載入 / 錯誤 / 長內容 / 權限）

| 狀態 | 內容 |
|---|---|
| **Empty** | 無背景圖：「先在『文字生成』出一張背景，或上傳一張」＋回 S4 捷徑。有背景無文字：自動放入範本預設插槽（headline/subhead/cta 帶 brief 草稿），引導「點任一文字層開始編輯」。 |
| **Loading** | 合成預覽 skeleton；套用範本時範本骨架先出灰框；字體載入中以系統字暫代並標「字體載入中」（載完替換，版面不跳）。 |
| **Error** | ① **字體缺失**：品牌字體載入失敗 → 該文字層標 ⚠「品牌字體暫時載不到，已用回退字體預覽，合成時會重試」，不阻擋。② **文字溢出**：文字超出插槽框 → 紅框＋「文字過長，已自動縮排/截斷」＋建議縮字或改插槽。③ **合成失敗**：`composeLayout` 失敗 → 操作級提示＋重試，圖層狀態不丟。 |
| **長內容** | 圖層多（>30）→ 圖層列虛擬滾動＋建議分組；內文插槽長文 → 自動分頁（多頁 carousel）或縮排＋「展開為多頁卡」。 |
| **權限** | 非擁有者唯讀（可看不可改）；品牌未鎖**不影響**單張合成（合成可在 draft 品牌下做），但批量/多尺寸/發佈仍需 S9 鎖品牌。 |

## 3. 進入＆離開條件
- **進入**：S5 核准素材後「去合成」；或 S4 結果「加入合成」；或 Flow 牆「套」一個版面範本起步。
- **離開（前進）**：「**合成這張 → 入庫**」呼叫 `composeLayout`，產物入 `digital_asset_library`（`composed:true`），進 S7（外部精修，可選）或 S8（核准）或 S9（多尺寸）。
- **後退**：「回 S5 改素材」（背景/元件回編輯）；「✎改範本」回選 `templateId`。
- **可分歧**：合成是 append-only，不覆寫 S4/S5 素材；可保留多個合成版本。

## 4. 分支與決策

| 分支 | 條件 | 行為 |
|---|---|---|
| **a 套版面範本** | 選 `templateId`（showcase/官方範本/Flow 牆「套」） | 載入插槽骨架，brief 文案灌入對應插槽；可 fork 公開範本 |
| **b 空白起步** | 不套範本 | 給最小預設（標題＋CTA 兩插槽），自由排 |
| **c 加講師為主視覺** | brief 有講師＋已去背 | 元件層放講師 cutout，文字層讓位（範本「人物海報」變體） |
| **d 文字溢出** | 文字超框 | 自動縮排→仍溢出則提示縮字/換插槽/分頁 |
| **e 對比不足** | 文字×背景 < AA | 標 `low_contrast`；建議：加深色遮罩條/換品牌色/移位；可打字覆寫 |
| **f 非品牌字體/色** | 嘗試選非品牌字/色 | 擋下＋「只能用品牌字體/色票，去 /brand 擴充？」 |
| **g 多頁卡（懶人包）** | 圖文卡類型 | 一個合成＝多頁；頁間共用 brand+範本，逐頁編插槽 |

## 6. route / procedure
- 路由：`/social/studio`（文字排版合成分頁）。
- 合成（**新 method**）：**`social.composeLayout`**（送 `LayoutReq`，回 `GenJob`，成本≈0 仍記帳）。後端走**確定性渲染**（HTML/CSS 或 SVG/Canvas headless），**不經擴散模型**。
- 範本骨架：`block_combos`（風格）＋ `featured_showcase`/範本（`templateId`，**注意** `showcase.templates` 待建）。
- 品牌套用：Tier-0 `blockCombos`(`kind:'brand'`)／Tier-1 `social.getBrandKit`（字體/色/logo/安全邊距）。
- 產物入庫：`digital_asset_library`（`composed:true`、`sourceStudio:'social'`）＋`project_asset_links`。
- 對比檢查：前端即時計算（WCAG AA），不足落 `consistency_vault` 旗標 `low_contrast`（經 `vault.update` payload，**校正**：vault 僅 CRUD，鎖/旗標語意在 payload 表達）。
