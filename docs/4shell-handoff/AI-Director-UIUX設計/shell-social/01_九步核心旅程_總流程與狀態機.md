# 01 · 九步核心旅程 — 總流程、全域狀態機、跨步驟 UX

> 這份檔把 Bruce 指定的**九步工作流**定義成 `/social` 的**核心使用者旅程**。每一步的逐步畫面規格在 `02`–`06`；本檔給**總流程、全域狀態機、跨步驟共用 UX、成本階梯、確認門總則、速查表**。
> 設計原則（全程）：**每一步先出建議、標成本、等確認，不靜默跑完；可回頭、可分歧、熟手可跳關；P0–P2 mock 全程零金鑰可演。**
> ⚙ **九步＝可設定的「預設範本」**：使用者可增/刪/重排/啟停/改名步驟、存自訂範本、重設回預設（編輯器與資料模型見 `09`）。本檔描述的是**預設九步範本**的內容與流程；**安全閘門（成本/品牌/來源）與步驟解耦、恆在**（`09` §6）。

```

      │                 │                   │                  ＋生成→存庫→重用      │
      │                 │                   │                  ＋Flow 電視牆延伸      │
      ▼                 ▼                   ▼                         │             │
 /social cockpit ◀──────────────────────────────────────────────────┘             │
                                                                                   ▼
 S9 完成專案 ◀─ S8 反覆修正 ◀─ S7 接入 Canva/Adobe ◀─ S6 圖層拼接 ◀─ S5 素材修改 ◀─┘
 (品牌鎖閘門     (stale/重生      (往返整合、整合點)     (composeLayout)   (image-edit/
```

**一條線的本質**：S1–S3 是「**想清楚要做什麼**」（零生成、零成本），S4–S6 是「**把它做出來**」（生成＋合成，成本集中在 S4），S7 是「**外部精修往返**」（可選），S8–S9 是「**收斂並送出去**」（品牌鎖閘門＋多尺寸＋發佈）。

**九步 ↔ 路由 ↔ 主要委派**：

| 步 | 名稱 | 主路由 | 主要委派/呼叫（真實 procedure，見 `08`） | 是否需確認門 |
|---|---|---|---|---|
| **S1** | 了解設計類型 | `/social` cockpit | `creativeProject.get`（讀上下文）；本地 designType 選擇 | 否 |
| **S2** | 設計 brief（五問） | `/social` cockpit ＋ `/social/brand` | `creativeProject.update`（存 brief）；品牌讀 `blockCombos.list`/`social.getBrandKit` | 否 |
| **S3** | 收集專案資料素材 | `/social` cockpit 右欄 | `assets.*`（既有資產）、上傳、`orbProxy.unifiedSearch`/`news.list`（時事選題） | 來源 HOLD（上傳/授權） |
| **S4** | 創作設計素材 | `/social/studio` | `generate.estimateCost → prepareJob/submitStudioJob → jobStatus → recordGenResult`；外部導入＝上傳 | **成本確認** |
| **S5** | 素材修改 | `/social/studio` | `generate.*`（image2image 轉繪/局部重繪）；微調 | 成本確認（再生成時） |

## 2. 全域狀態機（四個實體的狀態軌）

`/social` 全程圍繞四個實體的狀態流轉。**所有狀態 mock=real 一致**（P2 mock DataStore 也實作這些狀態），切真實判定不翻盤。

### 2.1 專案 Project（主幹）
`creative_projects`：`active`（進行中）。社群系列＝一個專案/輕量專案。所有產物掛其下，無孤兒。狀態本身不阻擋旅程，只承載 timeline。

### 2.2 品牌 BrandKit（= `/video` 角色鎖定的孿生）
```
draft ───▶ defined ───▶ locked ───▶（要改）unlock → version++ → 下游標 stale
              │                          │
   缺漏旗標：missing_logo / missing_palette / missing_font / low_contrast / superseded
```
- **硬條件**：**品牌 `locked` 才能進批量出圖／多尺寸匯出／發佈**（單張試做可放行）。
- 缺漏以**行內欄位提示**呈現（非報錯）；`low_contrast` 為可覆寫警告。

### 2.3 單張產物 Post-Asset
```
pending ───▶ generated ───▶ approved
                  │     └──▶ rejected
   缺漏旗標：off_brand（Gemini 感知比對偏離）/ unlicensed_source / low_contrast
```
- **硬條件**：**`approved` 才能匯出多尺寸／排程發佈**。

### 2.4 社群貼文 Post（Tier-1 聚合）
```
draft ───▶ ready ───▶ scheduled ───▶ posted
                          │      └──▶ failed（平台拒件/限流/token 過期）
   stale（品牌改版後）：可全部重生 / 選擇性重生 / 保留舊版(pinned_to_v{n})
```

### 2.5 狀態 × 步驟對照（哪一步推進哪個實體）

| 步 | 推進的實體狀態 |
|---|---|
| S2 | BrandKit `draft→defined`（填齊欄位） |
| S4 | Post-Asset `pending→generated` |
| S5/S6 | Post-Asset 維持 `generated`（修改/合成不改核准態） |
| S8 | Post-Asset `generated→approved`/`rejected`；品牌改版觸發 `stale` |
| S9 | BrandKit `defined→locked`；Post `draft→ready→scheduled→posted` |

## 3. 確認門總則（三道確認，寫 `orchestration_runs` 稽核）

接設計 §4.3／§7.4。`/social` 的品管脊椎與 `/video` **共用同一條**（確認門是唯一品管脊椎），UI 用設計系統的 `GateCard`（`.gate`，`state`=ready·partial·blocked）。三道對等確認：

| 閘門 | 觸發時機 | 行為（UI） | 覆寫規則 |
|---|---|---|---|
| **成本確認 `cost`** | 任何媒體生成（S4/S5 text2image/image2image） | 「預估 {N} pts，確認生成？」未確認不送生成；**積分制**：先扣後生成（原子）、**失敗全額退還**、最小 1／上限 500 pts | 成本階梯選最省可行；mock 期回固定 `estimatedCost`（pts）也照走 |
| **品牌確認 `brand`** | S9 批量出圖/多尺寸/發佈前 | 品牌未 `locked` → 鈕 disabled＋「去鎖定品牌」捷徑；偏離品牌標 `off_brand`＋建議 | `low_contrast` 可打字確認覆寫＋填 reason |
| **來源確認 `source`** | S3 上傳/S7 外部導入素材、S9 發佈前 | 「此圖含上傳/外部素材，確認你有使用權？」未確認 `HOLD` | 寫 `social_posts.assetSources[]` 留證 |

**閘門決策矩陣**（這張圖能不能往下發）：

| 情況 | 判定 | 行為 |
|---|---|---|
| 品牌未 `locked` | **BLOCK** | 批量/發佈 disabled；給去鎖捷徑（單張試做放行） |
| 對比未達 AA | **WARN（可覆寫）** | 標 `low_contrast`，建議調色；打字確認覆寫（記 reason） |
| 素材來源未確認 | **HOLD** | 跳使用權確認 modal；未確認不發佈 |
| 成本未確認 | **HOLD** | 跳成本確認 modal；未確認不送生成 |
| 品牌已鎖卻要改 | **UNLOCK 流程** | 解鎖 modal 顯示「將影響 N 篇既有貼文」→ 解鎖後 `version++`、下游標 `stale` |

> **覆寫一律打字確認＋填 reason**，寫稽核（誰/何時/為何），與 `/video` 一致。

## 4. 成本階梯（鐵則，全站同）

```
Deterministic（模板合成 composeLayout / 多尺寸重構）
 → Cache（已生成過的重用）
 → RAG（壓 brief 成精華）
 → 便宜 LLM（文案 suggestCopy）
 → Sonar（時事選題 researchTrends）
 → 高級 LLM
 → 媒體生成（text2image/image2image，永遠先估＋確認）← 唯一落最右段
```

`/social` 多數步驟落**左段（便宜/確定）**：文案便宜、合成≈0、多尺寸重構≈0；只有 S4/S5 的 text→image/image-edit 落最右段需成本確認。這讓 `/social` 單位成本遠低於 `/video`，適合高頻產出。**UI 要把這條階梯顯性化**：每個會花積分的動作旁標**積分徽章**（`~0 pts` / `~{N} pts`），生成鈕永遠先過成本門。**扣退即時回饋**：送生成 toast「已扣 {N} pts」；失敗 toast「已全額退還 {N} pts」。

## 5. 跨步驟共用 UX（每一步都遵守）

### 5.1 窄螢幕優先（社群多手機）
- 三欄 cockpit 在窄螢幕收成**頂部 tabs**（專案+品牌 / 創作 / 資產+風格），dock 變**底部列**。
- 確認門 modal、解鎖 modal、來源確認 modal 在窄螢幕**全螢幕**。
- Flow 電視牆在窄螢幕變**橫向滑動卡列**（一次一張，seed/prompt 收進卡底 expander）。
- 圖層拼接（S6）在窄螢幕：畫布在上、圖層列在下抽屜，屬性面板用 bottom-sheet。

### 5.2 無障礙 a11y
- 對比達 **WCAG AA**；尊重 `prefers-reduced-motion`（關掃光/呼吸/掃描）。
- 全鍵盤可達：`Ctrl+K`（cmdk）、`G` 系列跳路由（`G S`→cockpit、`G B`→brand、`G P`→publish）、`Esc` 關 modal、方向鍵走圖層列。
- 每個生成/匯出/發佈任務有 `aria-live` 進度播報；徽章 ✅/❌/⏳ 附文字標籤不只靠顏色。
- 焦點環用 `--ring`（`:focus-visible` 才出現），永遠可見。

### 5.3 i18n
- **全字串 zh-TW 外部化**（集中在 `07`，i18n key → 字串）。不在元件硬寫中文。

### 5.4 權限 / 未登入 / 草稿保存（跨步驟「權限狀態」總則）
所有受保護路由（`/social*`）的**權限狀態**統一處理，各畫面規格不再重述、只引用本則：

| 權限情形 | 行為 |
|---|---|
| **未登入** | 導登入頁，**保留 return URL ＋暫存當前草稿**（brief/文案/未存貼文寫 `project_notes_calendar` 暫存）；登入後回原步原狀態 |
| **非專案擁有者**（ACL） | 後端每條代理 procedure 穿過 `assertProjectOwnership`（`03` §8 證實）。前端：唯讀模式 banner「你沒有此專案的編輯權」，生成/鎖定/發佈鈕 disabled，可複製為自己的專案 |
| **積分不足** | 成本確認門顯示「積分不足，需 {N} pts」；**積分制**（不涉真實金錢、不需信用卡），給「改用更省的模型」或「了解積分」捷徑；不靜默失敗 |
| **品牌鎖權限** | 鎖/解鎖品牌需擁有者；協作者只能套用已鎖品牌 |
| **發佈通道未授權**（Postiz/平台 token） | 停在「已產出、可手動下載多尺寸包」，不阻斷創作主線；給「連接發佈通道」捷徑 |

### 5.5 長內容狀態（跨步驟「長內容」總則）
各畫面規格的「長內容」狀態統一引用本則：

| 長內容情形 | 處理 |
|---|---|
| **brief 是長文**（整篇文章轉懶人包） | 進 RAG/Context Packet 壓成 2k–8k 精華（`contextPacket.compileProject`）再給 Claude；**絕不整篇塞影像模型**；UI 顯示「已壓縮 N 字 → 精華」可展開原文 |
| **文案多版／超長** | 多版用卡片橫向選擇；單版超長收 `行高×6` + 「展開」；hashtag 超量折疊「+N」 |
| **資產庫/貼文清單長** | 虛擬滾動＋分頁（`continuation`）；篩選器（依比例/品牌/狀態/來源）置頂 |
| **圖層多（S6）** | 圖層列虛擬滾動；群組折疊；>30 層提示「建議分組」 |
| **多尺寸包尺寸多** | 預設集卡片 grid；批次匯出進度逐尺寸徽章；可全選/反選 |
| **行事曆貼文密集** | 月視圖一格 >3 篇折「+N」，點開當日列表 |

## 6. 全域空/載入/錯誤 baseline（各畫面只寫差異）

各畫面規格的四態只描述**該畫面特有**內容，下列 baseline 全域成立：

- **Empty**：永遠給**一句引導＋一顆主 CTA**，不留白屏。
- **Loading**：脊椎 chrome **先渲染**；內容區用 **skeleton**（不轉圈白屏）；長任務交 `BackgroundTasksContext` 背景輪詢，換頁不中斷、完成 toast。
- **Error**：**操作級 error boundary**（不整頁白），給原因＋重試 toast；生成失敗走**回退鏈 UI**（逐圖 ✅/❌/⏳＋重試），mock 可 `?fail=timeout|429|partial` 注入演練。
- **Success**：明確下一步 CTA（出文案草稿→下一步、圖回掛 assetId→送多尺寸…）。
