# 02 · 步驟 S1–S3 — 了解設計類型 / 設計 brief / 收集專案資料素材

> 旅程前段「**想清楚要做什麼**」：零生成、零成本（全落成本階梯左段）。主場＝`/social` cockpit。
> 每步固定六段：①畫面結構　②全狀態（空/載入/錯誤/長內容/權限）　③進出條件　④分支與決策　⑤microcopy　⑥route/procedure。
> 全域 baseline（空/載入/錯誤）、權限總則、長內容總則見 `01` §5–§6，本檔只寫差異。

## S1 · 了解設計類型（designType）

**目標**：讓系統與使用者一起確認「這次要做哪一種對外圖文」。這是整條旅程的定錨——設計類型決定後續預設比例、版面範本、文案結構與多尺寸預設集。

### S1.1 畫面結構與佈局（`/social` cockpit · 進站首屏）

cockpit 三欄殼載入，**中欄**為 S1 主舞台：

```
┌ 左：專案+品牌 ┬──────── 中：了解設計類型 ────────┬ 右：資產庫+風格庫 ┐
│ ActiveProject │  eyebrow：開始一篇社群創作          │ 近期產物（唯讀預覽）│
│ 面板：         │  ┌────────────────────────────┐  │ 風格庫 blockCombos │
│ · 當前專案名   │  │ 意圖框（GuidedJourney）      │  │ （唯讀預覽）        │
│ · 品牌徽章     │  │ 「用一句話說你想做什麼…」     │  │                    │
│ · 切換專案     │  └────────────────────────────┘  │                    │
│               │  — 或直接選類型 —                  │                    │
│               │  ⬚ 社群貼文圖  ⬚ 海報             │                    │
│               │  ⬚ 圖文卡     ⬚ 限動/Reels 封面   │                    │
│               │  ⬚ 多平台尺寸包                    │                    │
│               │  [上次未完成：療癒誌·春季講座 ▸繼續]│                    │
└───────────────┴────────────────────────────────────┴────────────────────┘
```

- **五種類型卡**（對映設計 §2.3 五產物，用設計系統 `TemplateCard`）：每張卡含縮圖、名稱、主要尺寸標籤、一句用途。卡片底 `--surface`，選中態描邊 `--accent` ＋ `--ring`。
- **意圖框**在類型卡上方：使用者可不選卡、直接打一句話（「想做一張春季禪修講座的 IG 貼文」），系統推論類型並預選對應卡（見分支 b）。
- **上次未完成**：若有 `draft` 貼文，頂部給「繼續上次」入口。

### S1.2 全狀態

| 狀態 | 內容 |
|---|---|
| **Empty**（無專案/首次） | 中欄一句「選一種類型，或用一句話告訴我你想做什麼」＋五張類型卡；左欄品牌面板顯示「尚未建立品牌 · 建立第一個品牌」CTA（不阻擋，可先選類型）。 |
| **Loading** | 脊椎 chrome 先渲染；中欄類型卡 skeleton（5 張灰卡）；右欄資產/風格 skeleton。 |
| **Error** | 讀專案上下文失敗 → 中欄操作級提示「載入專案上下文時出了點問題」＋重試；類型卡仍可選（類型選擇是本地狀態，不依賴後端）。 |
| **長內容** | 意圖框輸入超長 → 即時字數提示；若貼整段文章，提示「這看起來是長文，之後可一鍵壓成懶人包重點」（連到 S3/S4 RAG，§01 §5.5）。 |
| **權限** | 依 `01` §5.4：未登入導登入保留草稿；非擁有者唯讀＋可複製專案。 |

### S1.3 進入＆離開條件
- **進入**：意圖玄關路由到 `/social`（帶 active project），或脊椎切到 `/social`，或 `Ctrl+K`「社群創作」。
- **離開（前進）**：選定類型 → 中欄轉入 S2 brief 五問（同頁、不換路由，類型卡收為頂部 chips）。
- **離開（跳關）**：熟手 `Ctrl+K`→`/social/studio` 直接出圖（跳過 S1–S3）。

### S1.4 分支與決策

| 分支 | 條件 | 行為 |
|---|---|---|
| **a 直接選卡** | 點任一類型卡 | 設 `designType`，預載該類型的預設比例與版面範本候選，進 S2 |
| **b 意圖推論** | 在意圖框打字送出 | 委派 `sense.inferIntent` 推論類型→**預選**對應卡並高亮，附「我猜你要做 X，對嗎？〔換一種〕」；確認後進 S2，並把這句話帶入 S2 brief 的「主題」欄草稿 |
| **c 繼續未完成** | 點「繼續上次」 | 載入該 `draft` 貼文，跳到它停留的步 |
| **d 多平台尺寸包** | 選此卡 | designType=`multi_size`，S2 後直接側重 S9 多尺寸（提示「這類型重點在一次出全平台」） |

### S1.5 microcopy（zh-TW，key 見 `07`）
- eyebrow：`開始一篇社群創作`
- 意圖框 placeholder：`用一句話說你想做什麼，例如：春季禪修講座的 IG 宣傳貼文`
- 五類型卡：`社群貼文圖`／`海報`／`圖文卡（懶人包）`／`限動・Reels 封面`／`多平台尺寸包`
- 類型卡副標例：`IG／FB／Threads／X 單張或輪播 · 1:1 / 4:5 / 16:9`
- 推論確認：`我猜你想做「{type}」，對嗎？` ＋ `對，繼續` / `換一種`
- 繼續未完成：`繼續上次：{postTitle}`

### S1.6 route / procedure（見 `08` 詳表）
- 路由：`/social`（cockpit）。
- 讀上下文：`creativeProject.get`。
- 意圖推論：`sense.inferIntent`（**注意**：`sense` 僅 `inferIntent`，無 research）。
- 類型選擇：前端本地狀態（`designType`），隨 S2 一起 `creativeProject.update` 落盤（Tier-0）或入 `social_posts.draft`（Tier-1）。

## S2 · 設計 brief（五問：主視覺・精神・目的・客群・主題・講師）

**目標**：用結構化問答把腦中的圖文需求落成 brief，**同時把品牌與口吻定錨**。brief 餵 S4 文案（Claude 的 system 約束）與視覺生成 prompt。

### S2.1 畫面結構與佈局（cockpit 中欄 · 接續 S1）

類型卡收為頂部 chip（`類型：海報 ✎改`），中欄轉為**引導式 brief 表單**（一次顯示一組、可上下捲、左側進度點）：

```
┌ 左：專案+品牌 ┬──────── 中：設計 brief ────────┬ 右：資產庫+風格庫 ┐
│ 品牌面板：     │ 類型：海報 ✎                    │ 參考圖建議（依品牌） │
│ · 草稿/已鎖   │ ① 主視覺  你想要的畫面感覺？      │ 風格庫 blockCombos  │
│ · 缺漏提示    │   [文字]＋[風格 chips：療癒/極簡…] │ （可點：套風格）     │
│ · 去 /brand   │ ② 精神    這篇的氣質／調性？       │                    │
│   鎖定捷徑    │   [文字]（餵 voice&tone）         │                    │
│               │ ③ 目的    想達成什麼？〔報名/告知/ │                    │
│               │   品牌曝光/銷售〕(可多選)          │                    │
│               │ ④ 客群    給誰看？〔chips＋自填〕  │                    │
│               │ ⑤ 主題    講什麼？（S1 那句帶入）  │                    │
│               │ ⑥ 講師    誰主講／誰是主角？       │                    │
│               │   [選既有講師 ▾ / 自填 / 無]      │                    │
│               │ ────────────────────────────── │                    │
│               │ [略過細節，先出草稿]  [完成 brief →S3]              │
└───────────────┴───────────────────────────────┴────────────────────┘
```

**六欄設計細節**：
1. **主視覺**：自由文字＋風格 chips（風格 chips 來自 `block_combos`，點選＝把該 combo 帶入後續生成 prompt）。可附「上傳參考圖」入口（→ 走 S3 來源確認）。
2. **精神（調性）**：自由文字；此欄**直接餵品牌 `voice & tone`** 與文案 system 約束（如「溫暖療癒」）。
3. **目的**：多選 chips（`報名/活動告知`、`品牌曝光`、`知識分享`、`銷售/募款`）＋自填；決定 CTA 與文案結構。
4. **客群**：chips（`學生`、`上班族`、`家長`、`禪修同好`…）＋自填；影響用詞與平台建議。
5. **主題**：自由文字（S1 意圖那句自動帶入為草稿，可改）。
6. **講師／主角**：下拉選既有講師（讀講師名冊資料）／自填／選「無（純主題）」。選定後可一鍵把講師既有照片拉進 S3 素材（見分支 c）。

> **為何有「講師」一欄**：本平台多為講座／課程／活動宣傳，貼文常以**主講人**為主視覺。把講師設為一級 brief 欄位，下游可自動拉講師定裝照、把姓名/頭銜排進版面插槽（S6 slots）。

### S2.2 全狀態

| 狀態 | 內容 |
|---|---|
| **Empty** | 六欄皆空，每欄有 placeholder 與一句為什麼問（微提示）；底部「略過細節，先出草稿」永遠可按（brief 非強制全填）。 |
| **Loading** | 從 S1 進入即時渲染（無後端等待）；若載入既有 brief（編輯舊貼文）→ 欄位 skeleton。 |
| **Error**（表單級） | 存 brief 失敗 → 行內「暫存失敗，已保留你的輸入，稍後自動重試」（不丟輸入，背景重試 `creativeProject.update`）。 |
| **長內容**（brief 長文） | 主題/主視覺貼長文 → 顯示「已壓成重點（N 字 → 精華）〔看原文〕」，壓縮走 `contextPacket.compileProject`（§01 §5.5）；不把全文塞影像模型。 |
| **權限** | 非擁有者唯讀；品牌鎖定欄位若無權限顯示「只能套用已鎖品牌」。 |

### S2.3 進入＆離開條件
- **進入**：S1 選定類型後。
- **離開（前進）**：按「完成 brief →S3」或「略過細節，先出草稿」。前者帶完整 brief；後者帶部分 brief（缺欄標 `optional_skipped`）。brief 落 `creativeProject.update`（Tier-0）或 `social_posts.copy/brief`（Tier-1）。
- **離開（去鎖品牌）**：左欄「去鎖定品牌」捷徑 → `/social/brand`（見 `06` §2），回來保留 brief。
- **後退**：頂部類型 chip「✎改」回 S1。

### S2.4 分支與決策

| 分支 | 條件 | 行為 |
|---|---|---|
| **a 完整 brief** | 六欄填齊 | 帶完整 brief 進 S3；品牌 `voice&tone` 由「精神」欄草稿預填（去 `/brand` 可調） |
| **b 略過先出草稿** | 按略過 | 帶部分 brief 直接進 S4（cockpit 提示「資料越多，AI 文案越準」） |
| **c 選了講師** | 講師欄選既有人 | 提供「把 {講師} 的照片加入素材」一鍵 → 進 S3 預載該講師資產 |
| **d 風格 chip 選取** | 主視覺點 `block_combos` chip | 記住 combo id，S4 生成 prompt 自動帶入；`generation_history` 之後記「用哪個 combo 生」 |
| **e 品牌未建** | 左欄品牌=空 | 不阻擋 brief；但提醒「之後要批量出圖/發佈前需先鎖品牌」 |

### S2.5 microcopy
- 區段標：`設計 brief`；副：`填越多，AI 文案與視覺越貼近你要的`
- ① `主視覺`：`你想要的畫面感覺？`／placeholder：`例如：暖色調、留白、一位禪修者剪影`
- ② `精神 / 調性`：`這篇想給人什麼氣質？`／placeholder：`例如：溫暖療癒、安靜、可信賴`
- ③ `目的`：`想達成什麼？`（多選）：`報名・活動告知`／`品牌曝光`／`知識分享`／`銷售・募款`
- ④ `客群`：`給誰看？`／chips：`學生`／`上班族`／`家長`／`禪修同好`／`自填…`
- ⑤ `主題`：`這篇講什麼？`
- ⑥ `講師 / 主角`：`誰主講，或誰是主角？`／`選擇講師 ▾`／`自行輸入`／`沒有特定主角`
- 動作：`略過細節，先出草稿`／`完成 brief，去收集素材`
- 長文壓縮：`已整理成重點（{n} 字 → 精華）` ＋ `看原文`

### S2.6 route / procedure
- 路由：`/social`（cockpit 中欄）。
- 存 brief：`creativeProject.update`（Tier-0：brief 入專案 meta）／（Tier-1：`social.updatePost` 寫 `social_posts.copy/brief`）。
- 講師名冊：讀現有講師資料來源（如專案資產分類 `assets.list` 過濾講師，或既有講師表）；**實作時用 `08` 對照表確認講師資料的真實 procedure**。
- brief 長文壓縮：`contextPacket.compileProject`。
- 品牌欄讀：Tier-0 `blockCombos.list`（`kind:'brand'`）／Tier-1 `social.getBrandKit`。

## S3 · 收集專案資料素材（既有資產 ＋ 上傳 ＋ 時事選題）

**目標**：把這篇要用到的素材湊齊——專案既有資產、新上傳、以及（要蹭熱點時）經脊椎讀 news 的**時事選題**。為 S4 生成/合成備料。

### S3.1 畫面結構與佈局（cockpit 右欄主導 ＋ 中欄選題面板）

右欄「資產庫＋風格庫」成為 S3 主舞台，中欄出現**時事選題面板**（不另開 `/learn` 頁）：

```
┌ 左：專案+品牌 ┬──── 中：時事選題（可選） ────┬──── 右：素材收集 ────┐
│ 品牌面板      │ 〔讓 AI 找熱點角度〕          │ 分頁：               │
│               │ ┌──────────────────────────┐ │ [專案資產][上傳][講師] │
│               │ │ Sonar 回帶引用的選題卡：   │ │ ── 專案資產 ──        │
│               │ │ · 角度 A（來源 ¹）         │ │ ⬚⬚⬚ 既有圖（可多選）  │
│               │ │ · 角度 B（來源 ²）         │ │ ── 上傳 ──            │
│               │ │ [採用此角度→帶入主題]      │ │ ⤴ 拖放或選檔          │
│               │ └──────────────────────────┘ │   (來源確認 HOLD)      │
│               │  引用清單 ¹² …（可展開）      │ ── 講師素材 ──        │
│               │                              │ 來自 brief 的 {講師}照 │
│               │                              │ ──────────────────── │
│               │                              │ 已選 N 件 [帶去創作→S4]│
└───────────────┴──────────────────────────────┴───────────────────────┘
```

- **右欄＝真實數位資產庫（`/assets`）的嵌入視圖**（實站對齊，見下 S3.1'），不另造一套庫。多選資產進托盤。
- **時事選題面板**（中欄，可摺）：按「讓 AI 找熱點角度」→ Sonar 回**帶引用**的選題卡；採用某角度→寫回 S2 主題並標來源。
- **已選托盤**：底部顯示已選 N 件，「帶去創作 →S4」。

### S3.1' 對齊真實數位資產庫（`/assets`）

實站 `/assets` 是成熟的資產庫，`/social` 的素材收集（S3）、創作入庫（S4）、修改版本（S5）**全部掛這個真實庫**，不另造平行庫。嵌入視圖須具備實站既有維度：

- **搜尋鍵＝提示詞**：可**依提示詞搜尋**（prompt↔asset 已關聯，實站佐證），＋排序「最新優先」。這正是 S4/S5 提示詞庫（`PromptVault`）「由素材回溯 prompt／由 prompt 找素材」的同一條真實能力。
- **類型篩選（6）**：`圖片 / 影片 / 音樂 / 語音 / 腳本 / 打包`（`/social` 主用圖片，其餘可借）。
- **來源篩選（5＋）**：`創意工作室 / 導演AI / Image Studio / Video Studio / Pro Studio / 更多來源`（對映 `digital_asset_library.sourceStudio`；`/social` 產物 `sourceStudio:'social'` 落「創意工作室」族，外部往返落 `canva/adobe`）。
- **範圍切換**：`我的資產 / 團隊共享`；以及 `數位資產 / 個人資料庫系統` 兩庫切換。
- **動作**：`上傳資產`（→來源確認 HOLD）、分享「`+配額`」、資產卡「`展開詳情`」（看 prompt/seed/provider/來源/使用次數）。
- **跨片借素材**＝同一庫切「團隊共享／全部來源」即可（不開 `/video` UI）。

### S3.2 全狀態

| 狀態 | 內容 |
|---|---|
| **Empty** | 專案資產分頁：「這個專案還沒有素材 · 上傳或讓 AI 生成」；時事選題面板收合，顯示「想蹭熱點？讓 AI 找角度」。 |
| **Loading** | 資產縮圖 skeleton；時事選題→「正在讀新聞、找角度…」（Sonar/`orbProxy.unifiedSearch` 進行中，skeleton 卡）。 |
| **Error** | ① 上傳失敗：該檔卡標 ❌＋原因（過大/格式/網路）＋重試，其他檔不受影響。② 時事選題失敗：面板內「暫時找不到熱點，可手動輸入主題」＋重試（不阻擋主線）。 |
| **長內容** | 資產清單長 → 虛擬滾動＋篩選（比例/類型/來源/日期）；選題引用多 → 引用清單折疊「+N 來源」。 |
| **權限 / 來源** | **來源確認 HOLD**：上傳或外部素材 → 跳「此素材是你上傳的，確認你有使用權？」未確認標 `unlicensed_source`、不可進發佈（可先用於草稿）。非擁有者唯讀。 |

### S3.3 進入＆離開條件
- **進入**：S2 完成/略過後；或 S4 缺素材時回頭補。
- **離開（前進）**：「帶去創作 →S4」帶已選素材＋選定主題角度。
- **離開（無素材也可走）**：可不選任何既有素材直接進 S4（純文字生成）。
- **時事選題**為可選旁路，不擋前進。

### S3.4 分支與決策

| 分支 | 條件 | 行為 |
|---|---|---|
| **a 用既有資產** | 選專案資產 | 帶 assetId[] 進 S4（可作 image-edit 底圖或合成素材） |
| **b 上傳新素材** | 拖放上傳 | 上傳→**來源確認 HOLD**→確認後入 `digital_asset_library`（`sourceStudio:'upload'`）；授權證據標 `assetSources[].source:'uploaded'` |
| **c 時事選題** | 按找熱點 | `social.researchTrends`→委派 `commander.createIntent`/Sonar 讀 `news.list`/`orbProxy.unifiedSearch`；回帶引用選題；採用→寫回主題＋`sourceRefs` |
| **d 講師素材** | brief 有講師 | 預載講師照；可選為主視覺底圖/合成元件 |
| **e 跨 shell 借片素材** | 想用某支 `/video` 的角色圖 | **只透過脊椎讀 `digital_asset_library`**（`assets.list` 跨專案），不開 `/video` UI |
| **f 不蹭熱點** | 略過選題 | 直接用 S2 主題進 S4 |

### S3.5 microcopy
- 右欄分頁：`專案資產`／`上傳`／`講師素材`
- 專案資產空：`這個專案還沒有素材`／副：`上傳檔案，或直接讓 AI 生成`
- 上傳區：`拖放圖片到這裡，或點選檔案`／格式提示：`支援 JPG/PNG/WebP，單檔上限 {N}MB`
- 來源確認（HOLD modal）：`這張是你上傳/外部來的素材` ＋ `確認你有使用權？` → `我有使用權，繼續` / `先不要`
- 時事選題：`讓 AI 找熱點角度`／進行中：`正在讀新聞、找角度…`／採用：`採用此角度`
- 選題卡來源：`來源 {n}`（可點開原文）
- 已選托盤：`已選 {n} 件`／`帶去創作`
- 跨片借素材：`從資產庫挑既有素材（含其他專案）`

### S3.6 route / procedure
- 路由：`/social`（右欄嵌入 `/assets` 視圖＋中欄選題面板）。
- 既有資產：`assets.*`（`assets.list`＋**依提示詞搜尋** `notesCurator.searchAssets`；篩選 6 類型／5 來源 `sourceStudio`／範圍 我的·團隊／比例）；`digital_asset_library`。
- 上傳：既有上傳流 → `digital_asset_library`（`sourceStudio:'social'`）；授權證據另記 `assetSources[]`（`source:'uploaded'`，供發佈前來源確認）。
- 時事選題：`social.researchTrends` **façade →** `commander.createIntent`（plan）＋ **`orbProxy.unifiedSearch`** ＋ **`news.list`**（**校正**：`sense.research` 不存在，`sense` 僅 `inferIntent`）。
- 壓 brief/來源為精華：`contextPacket.compileProject`（含允許的 news 來源）。
- 來源確認稽核：寫 `social_posts.assetSources[]`（Tier-1）／`orchestration_runs`。
