## 1. 🔮 精靈系統 ＝ 右下角「光球助手」浮球（重要）

**真實**：右下角常駐**光球助手浮球**，會**主動跳泡泡**提醒（實見精靈「**守守**」提醒「提示詞庫沒用到」）。點開為**深色浮層面板**，分頁＝**本頁 / 提示詞 / 對話 / 專注流 / 積分 / 筆記**，內容**隨所在頁面情境變化**；導演 AI 模式帶**人格「沉穩型」**與**心情提示**。

**設計含義（亮色化要點）**：
- 浮球與面板由深色 → **亮色玻璃質感**（暖白半透明 ＋ backdrop-blur ＋ 柔陰影；clay 高光），但**保留**：情境分頁（6 頁）、主動泡泡、人格＋心情。
- **主動泡泡 ProactiveBubble**：浮球上方冒出小卡（精靈 emoji＋名＋一句提醒＋CTA）。例：`守守 · 你這次的提示詞還沒存進提示詞庫，要存起來重用嗎？→ 存入`。對應 16 條主動觸發（如 `notes_capture_suggested`、`prompt_too_short`、`feature_not_used`）。
- 「**生成 → 存庫 → 重用 ＋ Flow 展示牆**」要**與光球助手整合**：面板「提示詞」分頁＝提示詞庫瀏覽器（VaultBrowser）；另設 **Flow 展示牆**（把成功的「prompt→產出」工作流當可重跑的範例牆）。
- 人格／心情：導演 AI 人格（平靜/創意/技術，實站見「沉穩型」）＋心情提示顯示在面板頭。

**落到**：設計系統新增 `OrbAssistant`（浮球＋面板＋情境分頁＋ProactiveBubble）＋ `FlowWall`；/video 與全殼共用（脊椎層）。25 精靈完整名單由「深掘網站細節」工作階段從程式碼補。

## 2. 🎬 導演 AI（/director）＝ /video 旗艦核心

**真實**：
- 標語：「**對話→腳本→世界觀→分鏡→生成，全部在這頁完成，不再跳頁**」。
- **一條龍流程列**：每段帶**狀態**（對話 / 腳本 / 世界觀 / 分鏡 / 生成）。
- **模式分頁**：**對話模式 / 腳本分析 / 規劃模式 / 世界觀**。
- **右側 Storyboard 面板**（可隱藏）。
- 工具：**模板 / 對話紀錄 / 自動存筆記（開關）/ 隱藏 Storyboard**。
- 頂部提示：「**未綁定專案則不保存**」← 對應工作流第 1 步「腳本意圖／不綁定不保存」。

**設計含義**：
- /video cockpit 的**中欄＝導演 AI 控台**：在 `PersonaSwitch` 下方加**模式分頁**（對話模式/腳本分析/規劃模式/世界觀）；對話串為「對話模式」內容。
- **一條龍流程列** = 既有 `StageBar`（世界觀→腳本→分鏡→生成→成片）的對映；每段顯示狀態（done/cur/todo）。確認以 StageBar 表達「不跳頁、全在這頁」。
- **右欄 Storyboard 面板** = 既有 `MemoryDBTabs` 的「分鏡」分頁；加「隱藏 Storyboard」切換（收合右欄）。
- 工具列加：模板、對話紀錄、自動存筆記（Toggle）、隱藏 Storyboard。
- 頂部「未綁定專案則不保存」warning chip。

**落到**：`shell-video/video規格.md`（§1 版面、§2 Step1/Step5、§6 分頁）。

## 3. 🌍 世界觀系統（/director 內嵌，可收合）

**真實**：欄位群＝**角色 / 場景 / 風格**，各有**完成度**（如 角色 2/5、場景 2/3 17%、整體 4/15）；按鈕「**空白新增**」「**貼劇本 AI 全自動**」；可收合。

**設計含義**：
- /video「世界觀」模式分頁（或左欄上下文下方）放 **WorldPanel**：三組（角色/場景/風格）各一條**完成度 Meter ＋ N/M 計數**；整體完成度（如 4/15）。
- 兩入口按鈕：「空白新增」「貼劇本 AI 全自動」（後者＝ GuidedJourney 拆片）。
- 對映既有 `worldbuilding`（charactersJson/scenesJson）＋ `CharacterCard`（來源分級/鎖）。

**落到**：設計系統新增 `WorldPanel`/`CompletionMeter`；video規格 §6（世界觀分頁）。

## 4. 🗂 數位資產庫（/assets）— prompt↔asset 已關聯（重要驗證）

**真實**：
- **可依「提示詞」搜尋** → **prompt↔asset 已關聯**（強力佐證提示詞庫「真實記錄非 mock」）。
- 類型：**圖片 / 影片 / 音樂 / 語音 / 腳本 / 打包**。
- 來源：**創意工作室 / 導演AI / Image Studio / Video Studio / Pro Studio**。
- 範圍：**我的 / 團隊共享**；**22 資產**。

**設計含義**：
- **強化** `設計系統.md §9`「生成→存庫→重用」：prompt↔asset 在實站已可互查 → 提示詞庫的「搜尋 prompt 找素材」「由素材回溯 prompt」皆**真實可行**。
- 資產列篩選器補齊：類型 6 種、來源 5 種、範圍（我的/團隊）；以提示詞為搜尋鍵。
- 對映：`assets.*` / `digital_asset_library`（`sourceStudio` 對應五來源；`notesCurator.searchAssets/tagAssets`）。

**落到**：設計系統 §9.4 加註「實站 /assets 已可依提示詞搜尋」；資產列規格補篩選維度。

## 5. 🪙 積分（/dashboard?section=credits）

**真實**：平台積分制、**不需信用卡、不涉真實金錢**；**先扣後生成（原子）、失敗全額退還**、**最小 1pts / 上限 500pts**；分頁含 **使用統計 / 積分帳戶 / LangSmith**。

**設計含義**：
- 生成流程的「先估成本 → 確認 → 先扣 → 生成 → 失敗全退」要在 UX 明示（toast：`已扣 N pts`／失敗 `已全額退還 N pts`）。
- 文案避免「金錢」語氣；用「積分」。`/learn/credits` 與 `/dashboard?section=credits` 對齊。

**落到**：video規格 §2 Step3/Step5（扣點/退點 UX）；/learn 由平行工作階段處理積分頁。

## 6. 👤 個人化（左下頭像選單）

**真實**：
- **導覽列樣式**：浮動 Dock / 緊縮側欄 / 完整側欄。
- **密度**：緊湊 / 舒適 / 寬鬆。
- **位置**：靠左 / 置頂 / 靠右 / 置底。
- **沉浸模式**；另有「未整理區域」「管理後台」入口。

**設計含義**：
- 設計系統預留**密度 token**（緊湊/舒適/寬鬆＝padding/gap 三檔）與**導覽樣式變體**（Rail 可呈現為 浮動Dock / 緊縮 / 完整）。本里程碑預設「舒適 ＋ 完整側欄（Rail）」；變體列為設計系統擴充點。
- 位置（靠左/置頂/靠右/置底）＝ Rail/Nav 可擺位（後續）。

**落到**：設計系統 §「密度與導覽變體」（擴充點）；/settings 個人化由平行工作階段處理。
