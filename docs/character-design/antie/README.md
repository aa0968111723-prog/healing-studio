# 安倢（An-Tie）角色一致性模型

## 角色概述

**安倢**是一位 22 歲的東亞年輕女性，性格溫柔沉靜、善於觀察，擁有內在的寧靜力量。她熱愛冥想、閱讀、騎腳踏車和音樂，夢想是創作能為他人帶來溫暖的故事。

## 外觀設定

| 特徵 | 描述 |
|------|------|
| 髮型 | 黑色短髮（及肩），自然微捲波浪 |
| 臉型 | 圓潤溫和，帶有柔和的微笑 |
| 眼睛 | 溫暖的棕色，眼神寧靜而有深度 |
| 身高 | 約 160 cm |
| 體型 | 自然勻稱 |

## 服裝設定

### 主要造型（秋冬）
- 米色/奶茶色寬鬆針織毛衣（有小圖案裝飾）
- 深棕色圍巾
- 藍色牛仔褲
- 棕色短靴
- 木質佛珠手鏈

### 替代造型（春夏/冥想）
- 橘色寬鬆亞麻襯衫
- 黑色舒適長褲
- 木質佛珠手鏈

## 色彩調色盤

主色調為溫暖的大地色系：米色、棕色、橘色、牛仔藍，搭配金色暖光。

## 風格說明

本角色一致性模型採用**溫暖光影數位繪畫風格**，靈感來自 Pascal Campion 與 Atey Ghailan 的作品特色：

- 黃金時刻（Golden Hour）的戲劇性光影
- 柔和的散景（Bokeh）效果
- 電影感構圖
- 飽和但柔和的色彩
- 可見的繪畫筆觸質感
- 強烈的情感氛圍

## 使用指南

在生成新場景時，請確保以下一致性要素：

1. **髮型**：黑色及肩微捲短髮，不可改為長髮或直髮
2. **臉型**：圓潤溫和，表情以寧靜、微笑為主
3. **服裝色系**：以暖色大地色系為主（米色、棕色、橘色）
4. **配件**：木質佛珠手鏈為必備元素
5. **氛圍**：溫暖、寧靜、有療癒感
6. **光影**：優先使用黃金時刻的暖色調光線
