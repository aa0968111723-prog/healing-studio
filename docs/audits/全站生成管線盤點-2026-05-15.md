## A. AI 內容生成管線（server 端）

### A.1 入口層（Client 直接打的）

- **`server/routers/proStudio.ts:75-127`** — `generateAudio` / `checkAudioStatus` / `generateVoice` / `splitAudio` / `speechToText`  
- **`server/routers/director.ts`** — `pollGenerationTask`（背景工作長輪詢）、`executeGenerationTask`
- **`server/routers/imageStudio.ts`**、**`server/routers/videoStudio.ts`** — modality-specific
- **`server/routers/brainPipeline.ts`** — 編排 director + orb，再轉呼叫 compiler

### A.2 編排層（三層）

| 層 | 檔案 | 角色 |
|---|---|---|
| GlobalOrbExecutor | `client/src/agent/GlobalOrbExecutor.ts` | 瀏覽器內任務 runner，跨頁時暫停（self-jump gate, PR #563） |
| OrbTaskOrchestrator | `server/services/orbTaskOrchestrator.ts` | server 端 LLM 回覆 → typed `AgentAction` → 破壞性動作閘門 → feedback loop |
| Director Router | `server/routers/director.ts` | 無狀態的腳本／模板層，呼叫 Gemini 做 RAG ideation，**不直接觸發生成**，交給 brainPipeline／orb |

### A.3 Modality Compilers

| Modality | 檔案 | Provider |
|---|---|---|
| Image | `server/_core/imageGeneration.ts:37-119` | FAL（flux-pro 等） |
| Audio | `server/services/audioCompiler.ts` | Suno（via fal proxy） |
| Video | `server/services/videoCompiler.ts` | FAL（kling/runway/pixverse/minimax） |
| Voice | `server/services/voiceCompiler.ts:71-80` | ElevenLabs（含 SSML） |

四個 compiler 都實作 `compile(input): { prompt, sections, logs }` — 介面有 convention 但**沒抽共用介面**，行為靠人工保持一致。

### A.4 Provider Adapter

- **註冊表**：`server/services/providerRouter.ts:66-243`，含 `enabled / priority / requiredEnvKeys / fallbackProviderIds / estimatedCostTier`
- **各家 adapter**：`server/services/ai-adapters/providers/{fal,gemini,elevenlabs,suno}.adapter.ts`
- **中央 dispatcher**：`server/services/falDispatcher.ts:46-127` — submit、自動降級、LangSmith telemetry、扣點對帳
- **Model catalog**：`server/services/falModels.ts:115-500+`，16 大類、50+ 模型，已內含 `disabled` 標記（例：`elevenlabs/tts/flash-v2.5 broken upstream 2026-05`）

### A.5 事件 / 進度系統

- `server/generationEvents.ts:90-120` — in-memory `GenerationEventBus`
- 事件型別：`thought-update / progress / complete / error / step_complete / task_done / step_verifier_failed / chain_started / chain_completed`
- SSE 端點：`server/sseRoute.ts:19-88`（heartbeat 15s、TTL 5min）

### A.6 成本 / 信用閘門

- 預估：`server/services/modelPricing.ts → estimatePoints()`
- 預扣：`server/routers/proStudio.ts:57-71 → chargeForFalTask()`
- 對帳：`server/services/orbCostGuard.ts → deductCredits / reconcileCredits / refundUserPoints`
- 後驗分析：`server/services/costAnalytics.ts:28-100` — 包含 `detectRetryChains / calculateWasteCost / projectMonthlyCost`，**目前只在 admin 面板用，沒接到生成決策**

### A.7 持久化

| 表 | 觸發者 | 用途 |
|---|---|---|
| `users` | auth、扣點 | 配額、orb 記憶摘要 |
| `background_jobs` | director.pollGenerationTask | 狀態、resultJson、progress |
| `generation_history` | history、export | modality、prompt、resultUrl、cost、rating |
| `agentPreferences` | orbAgentPipeline | confirmationPolicy、costBudget、perceptionLevel |
| `customBlocks` | audio/video compiler | 使用者存的 block presets |
| `orbScheduledJobs` | orbScheduler | 跨重啟的 cron 任務 |

### A.8 痛點（按嚴重度）

🔴 **致命**
1. **fal 派發碎片化**：`dispatchFalQueueTask()` 已存在，但 image/audio/video router 各自包了一層 `falQueueSubmit()`；header、webhook URL、error wrap 重複四份。
2. **預扣款競態**：`chargeForFalTask()` 先扣點再送 fal，fal submit transient fail → 用戶損失點數。建議用「hold」狀態 + timeout 自動釋放。
3. **`backgroundJobs` 與 `generationHistory` 沒外鍵**：webhook 完成後沒自動補建 history row，舊 job 無 TTL，會堆積。

🟡 **中等**
4. **Director knowledge_base 與 compiler API drift**：`GENERATION_MODALITIES_KNOWLEDGE` 注入 prompt，但沒有測試確認 prompt 範例和 compiler 簽章一致。
5. **三組事件總線**：`generationEvents.ts` + `orbChatProgress.ts` + `orbTaskObserver.ts`。Client 要訂三條才看得到完整狀態。
6. **Compiler 沒做 schema validation**：SSML / prompt length 沒驗，ElevenLabs 拒收會整個 job 默默失敗。

🟢 **輕微**
7. `global-orb-executor.test.ts` 測的是 client 端邏輯卻放在 `/server`。
8. `costAnalytics.detectRetryChains()` 沒接到 orbCostGuard 做 auto-downgrade。
9. `FALLBACK_CHAINS` model id 沒 compile-time 檢查；現有測試又因 env 設定常被 skip。
10. Voice compiler 的 `EmotionProfile` 寫死，沒讓使用者透過 `customBlocks` 存自己的 voice preset。
